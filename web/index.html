C* Studio 帮助

    

      

        
F5编译并运行（等价于点「运行」）

        
Esc停止正在跑的程序

        
F1打开本帮助

        
Ctrl+S保存（第一次会问存在哪里）

        
Ctrl+Shift+S另存为

        
Ctrl+O / Ctrl+N打开 / 新建

        
Ctrl+C / Ctrl+V / Ctrl+X复制 / 粘贴 / 剪切（代码和积木都通用）

        
Ctrl+Z / Ctrl+Y撤销 / 重做（代码视图；积木视图在点上积木后按）

        
Tab缩进四格

        
Delete积木视图里删除选中的积木

        
「⚡ 快编」按钮快编开关：开着跳过溢出/越界检查（运行更快，出错不再提示），关掉带完整检查（默认）

        
「格式化」按钮自动理清缩进、一句一行

        
「代码 / 积木」按钮两种看法随时切换，改哪边都算

      

      

        程序写完按 运行：有问题会列在下面「问题」里，点一条就跳到出错的那一行。

        底部的四个小圆点分别是严重（程序跑不起来）、语法（写法不对）、拼写（名字打错了，会告诉你像哪个）、提示（只是建议，不算错）。

        代码视图里：颜色按分类分（和积木箱的十类一一对应），鼠标停在词上会弹出它的用法和写法；选中的文字是半透明的，不挡字。

        积木视图里：左边分类点开挑一块，点它就加到程序里；拖动积木换位置；点黄色小格子改名字，鼠标停上去会说明这一格填什么；
        括号里的 ＋ 用来加参数（空括号里的 ＋ 能新建参数）；选中一块积木后，Ctrl+C/X 复制剪切、Ctrl+V 粘贴、Ctrl+Z/Y 撤销重做都能用。
