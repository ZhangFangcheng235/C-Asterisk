### 0.4.2 的类型名（重点）

0.4.2 用下面这套类型名。**新写的程序一律用这套**。

| 类型 | 含义 | 写法示例 |
|------|------|----------|
| `int` | 整数（64 位） | `int 分数 = 90;` |
| `float` | 小数 | `float 价格 = 3.5;` |
| `string` | 字符串（一串文字） | `string 名字 = "小明";` |
| `char` | 单个字符 | `char 字母 = 'A';` |
| `bool` | 真 / 假 | `bool 及格 = true;` |
| `none` | 没有返回值（只用在函数类型上） | `none 打印(string s) { ... }` |

老版本的名字**还能编译**，只是编辑器会给一条"提示"级的提醒：

| 老名字 | 现在写 | 说明 |
|--------|--------|------|
| `number` | `int` | 整数，完全一样 |
| `real` | `float` | 小数，完全一样 |
| `text` | `string` | 字符串，完全一样 |
| `letter` | `char` | 单字符，完全一样 |
| `void` | `none` | 无返回值，完全一样 |
| `func` | `function` | 定义函数，完全一样 |
| `start { }` | `function main() { }` | 程序入口，完全一样 |
| `say` | `print` | 打印一行，完全一样 |

老名字叫"软弃用"：不算错误、不影响编译，只是不推荐。看别人的老代码时不用慌，但你自己写新代码时请用新名字。

### 关于"窗口程序"和"C 语言"

C* 里最特别的一条是：程序第一行写 `use "C_OPED.cash";`，就能直接开 Windows 窗口，还能直接调用 C、C++、Win32 头文件里的函数。这条线从第 8 章开始讲。

这里先记住一条限制：**只有 C 和 C++ 的世界是对你打开的，C# / .NET 没有 C 头文件，用不了。**

## 第 1 章　认识 C* 与开发环境

### 学习目标

- 说清 C* 是什么、源文件后缀是什么、编译器和编辑器分别叫什么。
- 用 C* Studio 写出、运行第一个程序，会用 F5 运行、Esc 停止。
- 分清编辑器状态栏上的四级问题：严重、语法、拼写、提示，会用"问题"面板跳到出错行。
- 会在命令行用 `bin\caskc.exe` 编译和运行程序，会用 `--keep` 看一眼生成的 C 代码。
- 知道中文全角标点为什么会让程序报错。

### 任务引入

第一天进机房，老师要求每人交一个能跑的程序，屏幕上打印一张"自我介绍卡片"，最后一行写自己的名字。要求用编辑器写、能运行、能保存。

这个任务只有四行输出，但它把一天的流程都走完了：新建文件、写代码、编译、运行、保存、交作业。做不完这个任务，后面所有实验都无从开始。

### 知识准备

#### 1.1 C* 是一门什么样的语言

| 特点 | 具体表现 |
|------|----------|
| 语法像 C | 大括号 `{ }`、分号 `;`、`if/for/while` 的写法和 C 一样 |
| 关键字看得懂 | 输出用 `print`，循环用 `for`、`while`，判断用 `if` |
| 变量名可以用中文 | `int 分数 = 90;`、`string 名字 = "小明";` |
| 出错不闷头乱算 | 数组越界、除以零、整数溢出都会当场停下并指出出错行 |
| 两种写法 | 代码视图写 `.cask` 文件，积木视图拖积木，两边随时切换 |
| 先翻译成 C 再编译 | `.cask` 先变成 C 代码，再交给 gcc 编成真正的 exe |

最后一条很关键：**C* 程序最后就是 C 程序**。所以第 10 章讲怎么调用 C 函数，附录 C 讲 C* 和 C 的对照关系——你现在写的每一行，都知道它变成 C 是什么样子。

#### 1.2 三个东西：源文件、编译器、编辑器

| 名字 | 文件 | 干什么 |
|------|------|--------|
| 源文件 | `某某.cask` | 你写的代码，后缀固定是 `.cask` |
| 编译器 | `bin\caskc.exe` | 把 `.cask` 变成 `.exe` |
| 编辑器 | `bin\caskide.exe` | C* Studio，写代码、点按钮运行、看错误都在这儿 |

#### 1.3 第一个程序

一个 C* 程序从 `function main()` 开始执行。下面是最小的完整程序：

```cask
// hello.cask -- 第一个 C* 程序
function main() {
    print "你好，C*！";
    print "这是我的第一个程序。";
}
```

运行结果：

```text
你好，C*！
这是我的第一个程序。
```

三个要点：

- `function main() { }` 是**入口**，程序从这里第一行开始跑。每个程序只能有一个。
- `print ...;` 是输出语句，打完之后**自动换行**。一句话结束要有分号 `;`。
- `//` 后面是注释，写给同学和以后的自己看，编译器不看。

想不换行地输出（比如"请输入："），用 `show`：

```cask
// 输出小例子
function main() {
    show "请输入你的名字：";
    print "（这一行是接着上一行打的）";
}
```

运行结果：

```text
请输入你的名字：（这一行是接着上一行打的）
```

#### 1.4 C* Studio 界面

双击 `bin\caskide.exe` 打开编辑器。

| 位置 | 说明 |
|------|------|
| 顶部菜单栏 | 文件 / 编辑 / 视图 / 生成 / 调试 / 帮助 |
| 工具栏 | 新建、打开、保存、另存为、运行、停止、代码 / 积木、格式化、编码、帮助 |
| 中间 | 代码编辑区（左侧有行号栏） |
| 下方 | "输出"面板，程序运行时显示在这里；程序要求输入时，这里出现输入行 |
| 更下方 | "问题"面板，列出所有编译问题 |
| 状态栏 | 文件名、编码、行列、严重 / 语法 / 拼写 / 提示 四个计数、版本号 |

常用按键：

| 按键 | 作用 |
|------|------|
| F5 | 编译并运行 |
| Esc | 停止正在运行的程序 |
| F1 | 打开帮助 |
| Ctrl+S | 保存（第一次会问存到哪儿） |
| Ctrl+Shift+S | 另存为 |
| Ctrl+O / Ctrl+N | 打开 / 新建 |
| Tab | 缩进四格 |
| Delete | 积木视图里删除选中的积木 |

**代码视图与积木视图**：工具栏上的"代码 / 积木"两个按钮切换两种看法。积木箱分十类：输出输入、变量数据、运算、判断、循环、函数、字符串与数组、窗口程序、CSS 美化、其它。其中"窗口程序""CSS 美化"是头文件插件——程序里 `use` 了对应的 `.cash` 才出现，没 `use` 就不显示；注释行画成一块能点改的绿色积木，`use` 积木拉一条线连到右侧的头文件概述卡片。点一块积木就插进程序，拖动可以换位置，点积木上的黄色小格子可以改名字和数值。

两边是**同一个程序**：你对积木的每一次操作，都立刻改写代码文本；代码永远是本体，积木只是它的一种表示。所以不会出现"积木和代码对不上"的情况。

**边写边查**：停下打字大约半秒，编辑器会在后台跑一遍检查，把问题列在"问题"面板里，并在行号栏上标出出错的行。点面板里的一条，光标就跳到那一行。

#### 1.5 从 .cask 到 .exe，中间发生了什么

在命令行里可以自己看一眼这中间的过程。下面命令里的 `程序.cask` 换成你自己的文件名：

```bat
bin\caskc.exe 程序.cask                 :: 编译出 程序.exe（默认优化）
bin\caskc.exe 程序.cask --run           :: 编译完立刻运行
bin\caskc.exe 程序.cask -o 我的.exe      :: 指定输出的 exe 名字
bin\caskc.exe 程序.cask --keep          :: 保留生成的 C 代码（程序.cask.gen.c）
bin\caskc.exe 程序.cask --check         :: 只检查，不生成任何文件
bin\caskc.exe 程序.cask -v              :: 显示真正执行的 gcc 命令
bin\caskc.exe 程序.cask -g              :: 调试版，带详细信息
```

`--keep` 生成的 `.gen.c` 文件可以用记事本打开，那就是你写的 C* 翻译出来的 C 代码。第一章先知道有这回事，附录 C 会教你怎么读它。

#### 1.6 四级问题：严重、语法、拼写、提示

编辑器把发现的问题分成四级，状态栏上一直显示四个计数：

| 级别 | 颜色 | 含义 | 程序还能跑吗 |
|------|------|------|--------------|
| 严重 | 红 | 语义错误：名字没定义、类型对不上、常量写了变量 | 不能 |
| 语法 | 橙 | 写法不对：少了分号、括号不配对、用了全角标点 | 不能，但编译器会跳过错处继续查，一次报多条 |
| 拼写 | 绿 | 名字打错了，通常会附上"是不是想写 ×××" | 不能 |
| 提示 | 蓝 | 只是建议，比如你还在用老写法 `say`、`number` | 能，不影响 |

命令行加上 `--check --diag` 可以看到机器格式的问题列表，每行格式是 `级别|行|列|说明`：

```bat
bin\caskc.exe 程序.cask --check --diag
```

#### 1.7 让程序跑起来

在编辑器里按 F5。编译没问题就开始跑，输出显示在下面的"输出"面板。程序结束时面板里出现 `[结束，退出码 0]`。要中途停下按 Esc。

在命令行里则用 `--run`：`bin\caskc.exe 程序.cask --run`。

### 任务实施

任务：做一张会打印在屏幕上的自我介绍卡片。

**第 1 步　新建文件。** 在编辑器里按 Ctrl+N，工具栏点"保存"，文件名叫 `card.cask`。后缀一定要是 `.cask`。

**第 2 步　写代码。** 逐行敲进下面的内容。注意标点全部用**英文半角**：分号是 `;` 不是 `；`，引号是 `"` 不是 `“ ”`。

```cask
// card.cask -- 自我介绍卡片
function main() {
    print "===== 自我介绍 =====";
    print "姓名：李明";
    print "专业：软件技术";
    print "班级：软件 2401";
    print "爱好：打篮球、写代码";
    print "===== 谢谢观看 =====";
}
```

**第 3 步　运行。** 按 F5。输出面板里应该出现：

```text
===== 自我介绍 =====
姓名：李明
专业：软件技术
班级：软件 2401
爱好：打篮球、写代码
===== 谢谢观看 =====
```

**第 4 步　在命令行里跑一遍。** 打开命令行，`cd` 到 `C_AS` 目录：

```bat
bin\caskc.exe card.cask --run
```

看到的输出和编辑器里一样。

**第 5 步　故意写错一次，认识报错。** 把第 3 行的分号删掉，再按 F5。问题面板会出现一条语法问题，大意是这一行少了分号。这就是"语法"级。

再把 `print` 写成 `prnt`，问题面板给出的是"拼写"级，还会问你"是不是想写 print"。

**第 6 步　看一眼生成的 C。** 在命令行里：

```bat
bin\caskc.exe card.cask --keep
```

旁边会多出一个 `card.exe.gen.c`。打开看一眼前面的几行就能看到：`print "..."` 变成了 `cask_p_str("...")` 加一个换行。不用看懂细节，知道有这么个中间文件就够了。

### 拓展与规范

**命名规范。** 变量名、函数名用"看得懂"的名字：`总分`、`平均分`、`isPassed` 都比 `a`、`b`、`x1` 好。小写英文加下划线、或者直接用中文，两种都行，一个项目里保持统一。名字不能以数字开头。

**注释。** `//` 写一行注释，`/* 多行 */` 写多行。注释写"为什么这么做"，不要复述代码：

```cask
// 不好：把分数加进去
// 好：这里按 60 分算及格（教务规定）
总分 = 总分 + 分数;
```

**缩进。** 一个大括号里缩进四格。工具栏的"格式化"按钮能一键理清缩进，写完点一下再交。

**保存编码。** 文件保存为 UTF-8。想用中文变量名就必须是 UTF-8。工具栏"编码 ▾"里可以一键"转成 UTF-8"。

**中文标点是最常见的入门坑。** 输入法在中文状态下打出的 `；`、`，`、`“ ”`、`（）` 都不是 C* 的符号。全角分号会报语法错误，全角引号会让编译器把一整段当成一个没见过的名字。

**别把变量名写成关键字。** `int print = 1;` 不行，`print`、`if`、`for`、`int` 这些是关键字，还有 `IF`、`SUM`、`LEN` 这些内置函数名也不能当变量名。

**一个程序只能有一个 `function main()`。** 多了会报错。

### 本章小结

- 源文件后缀是 `.cask`，编译器是 `bin\caskc.exe`，编辑器是 `bin\caskide.exe`（C* Studio）。
- 程序从 `function main() { }` 开始执行；`print` 输出并换行，`show` 输出不换行；`//` 写注释。
- 顺序是：写代码 → 编译 → 运行。编辑器按 F5，命令行用 `--run`；要停按 Esc。
- 问题分四级：严重、语法、拼写、提示。前三级必须改掉，提示可以不管但建议改。
- `.cask` 先翻译成 C，再由 gcc 编成 exe；`--keep` 能留下中间那份 C 代码。
- 标点必须用英文半角；中文只用在字符串和名字里。

## 第 2 章　数据类型与变量

### 学习目标

- 分清 `int`、`float`、`string`、`char`、`bool` 五种类型，知道各自该用在什么地方。
- 会声明变量、给变量赋值、用 `constant` 定义常量。
- 会用 `print`、`show` 输出，用 `input` 读入一个值。
- 知道 `int` 和 `float` 之间怎么转换，知道为什么 `int x = 3.5;` 通不过。
- 知道小数打印出来为什么和想的不太一样。

### 任务引入

班主任要一张"新生报到信息卡"：程序逐个问姓名、年龄、身高、性别，最后按固定格式打印一张卡片，身高要保留一位小数。

这类"问几个问题、算一下、打一张单子"的小程序，是后面所有项目的骨架。这个任务里你会遇到本章所有类型，也会遇到两个容易踩的地方：小数怎么打印、整数和小数怎么互相转换。

### 知识准备

#### 2.1 五种类型

| 类型 | 存什么 | 写法 | 底下的 C 类型 |
|------|--------|------|----------------|
| `int` | 整数，64 位 | `int 分数 = 90;` | `long long` |
| `float` | 小数 | `float 价格 = 3.5;` | `double` |
| `string` | 一串文字，用双引号 | `string 名字 = "小明";` | `char *` |
| `char` | 一个字符，用单引号 | `char 等级 = 'A';` | `char` |
| `bool` | 真或假 | `bool 及格 = true;` | `int`（1 表示真） |

要紧的几条：

- 字符串用**双引号**，单字符用**单引号**。`"A"` 是字符串，`'A'` 是字符，两者不通用。
- `int` 有范围：大约 ±9.2 × 10^18。超出会报错，不会悄悄算错（见附录 B）。
- `string` 的内容**不能被原地修改**：`名字[0] = 'X';` 这样的写法不允许。要改就用拼接，见第 6 章。
- `bool` 只有 `true` 和 `false` 两个值，打印出来的就是这两个词。
- `none` 不是"存东西"的类型，它只表示"这个函数不返回结果"，第 5 章讲。

#### 2.2 声明变量

格式是 `类型 名字 = 初值;`，初值可以省略：

```cask
// 变量小例子
function main() {
    int 分数 = 90;
    float 单价 = 3.5;
    string 名字 = "小明";
    char 等级 = 'A';
    bool 及格 = true;

    print 分数;
    print 单价;
    print 名字;
    print 等级;
    print 及格;
}
```

运行结果：

```text
90
3.5
小明
A
true
```

几条规则：

- 一个声明里可以连着写多个：`int a = 1, b = 2;`
- **没写初值的变量会自动变成 0**（`float` 是 0，`string` 是空，`bool` 是 `false`，数组全是 0）。不会像 C 那样读到垃圾值。
- 变量必须**先声明再使用**，而且全局变量要写在用它的函数**前面**。
- 名字可以用中文，前提是文件保存为 UTF-8。
- 名字不能和关键字、内置函数名重复，也不能用 `main`。

#### 2.3 常量

固定不变的值用 `constant`：

```cask
constant int 满分 = 100;
constant float 税率 = 0.13;

function main() {
    int 得分 = 85;
    print "得分率 ", 得分 * 100 / 满分, "%";
    print "含税价 ", 100 * (1 + 税率);
}
```

运行结果：

```text
得分率 85%
含税价 113
```

两条硬规定：

- `constant` 只能写在**最外层**（函数的 `{ }` 之外）。写在函数里面会报错。
- 常量的值必须是**编译时就能算出来的**：字面量、四则运算、别的常量。函数调用、变量、数组下标都不行。
- 常量名在程序里唯一，不能和变量重名。

#### 2.4 类型转换

C* 的类型转换规则很短，记住两条：

- **`int` 可以自动变成 `float`**：`float 小 = 3;` 得到 3。
- **`float` 不能自动变成 `int`**：`int 整 = 3.5;` 会报严重错误 `不能把 float 放进 int`。想转必须自己写清楚是"向下取整"还是"四舍五入"。

```cask
// 转换小例子
function main() {
    float 单价 = 19.9;
    int 元 = INT(单价);          // 向下取整：19
    int 凑整 = ROUND(单价);       // 四舍五入：20
    float 小数部分 = 单价 - 元;

    print "INT 得到 ", 元;
    print "ROUND 得到 ", 凑整;
    print "小数部分 ", 小数部分;
}
```

运行结果：

```text
INT 得到 19
ROUND 得到 20
小数部分 0.899999999999999
```

最后一行值得停一下：19.9 减去 19 按理是 0.9，为什么打出 `0.899999999999999`？因为小数在计算机里是用二进制近似存的。**比较小数不要用 `==`**，要用差值的绝对值小于一个很小的数来判断：

```cask
// 小数不能直接比相等
function main() {
    float a = 0.1 + 0.2;
    if (a == 0.3) { print "相等"; }
    else { print "不相等，差 ", a - 0.3; }

    if (ABS(a - 0.3) < 0.000001) { print "在误差范围内算相等"; }
}
```

运行结果：

```text
不相等，差 5.55111512312578e-17
在误差范围内算相等
```

#### 2.5 输入输出

| 语句 | 用法 | 说明 |
|------|------|------|
| `print 值, 值, ...;` | `print "总分 ", 总;` | 一次输出多个值，数字、文字、真假都能混着写，**最后换行** |
| `show 值, ...;` | `show "请输入：";` | 和 `print` 一样，但**不换行** |
| `input 变量;` | `input 年龄;` | 从键盘读**一整行**，按变量类型自动解析 |

`input` 是个**语句**，后面直接跟变量名，不要写括号：

```cask
// 输入小例子（需要运行后手动输入）
function main() {
    show "请输入你的名字：";
    string 名字;
    input 名字;
    print "你好，", 名字, "！";
}
```

运行（在 `请输入你的名字：` 后面输入"小明"再回车）：

```text
请输入你的名字：小明
你好，小明！
```

`input` 一次读一整行，所以数字、文字、字符换着输入也不会互相干扰。数字行里输入了非数字，程序会提示重输。`char` 取这一行里第一个非空白字符。

### 任务实施

任务：做一张"新生报到信息卡"。

**第 1 步　想清楚要问什么、要打印什么。**

| 问什么 | 类型 |
|--------|------|
| 姓名 | `string` |
| 年龄 | `int` |
| 身高（米） | `float` |
| 性别代号 | `char` |

要打印的卡片固定 5 行，其中身高保留一位小数。

**第 2 步　写程序。** 新建 `enroll.cask`：

```cask
// enroll.cask -- 新生报到信息卡
constant string 校名 = "职业技术学院";

function main() {
    show "请输入姓名：";
    string 姓名;
    input 姓名;

    show "请输入年龄：";
    int 年龄;
    input 年龄;

    show "请输入身高（米）：";
    float 身高;
    input 身高;

    show "请输入性别代号（M/F）：";
    char 性别;

    print "-----------------------------";
    print 校名, " 新生报到信息卡";
    print "姓名：", 姓名;
    print "年龄：", 年龄, " 岁";
    print "身高：", ROUND(身高, 1), " 米";
    print "性别：", 性别;
```

**第 3 步　运行并输入数据。** 按 F5，按提示依次输入。比如输入 `李明`、`18`、`1.75`、`M`，输出是：

```text

请输入年龄：18
请输入身高（米）：1.75

性别：M

```

**第 4 步　检查类型用对了没有。**

- 年龄必须是 `int`。如果误写成 `float`，打印出来会是 `18`（整数值的小数打出来不带小数点），但后面做"明年几岁"的加法就容易出问题。
- 身高必须是 `float`。写成 `int`，输入 1.75 时程序会拒绝这一行，要求重输。
- 性别是**单个**字符，所以用 `char`，不是 `string`。
- `ROUND(身高, 1)` 是"四舍五入保留一位小数"。`ROUND` 给两个参数时返回小数，给一个参数时返回整数。这里输入 1.75，保留一位小数就是 1.8，说明取位确实生效了。

### 拓展与规范

**声明和赋值分开写还是合起来写。** 本项目里 `string 姓名; input 姓名;` 是分开的，因为要读入的值必须在 `input` 之前先声明好。如果初值确定，就直接写在一起：`int 满分 = 100;`。

**小数打印的真相。** C* 打印小数时保留 15 位有效数字：

| 代码 | 打印结果 | 原因 |
|------|----------|------|
| `print 2.0;` | `2` | 末尾的 `.0` 不打印 |
| `print 1.0 / 3.0;` | `0.333333333333333` | 15 位有效数字 |
| `print 0.1 + 0.2;` | `0.3` | 近似误差被截断掉了 |
| `print 19.9 - 19;` | `0.899999999999999` | 误差露了出来 |

所以：**要给人看的小数，用 `ROUND(值, 位数)` 控制位数**；**判断两个小数相等，用差值小于一个很小的数**。

**浮点数的显示误差不影响加减。** `19.9 - 19` 打印得难看，但它确实约等于 0.9，接着算下去没问题。

**常量写在哪里。** 一个文件里所有 `constant` 都放在最上面、函数之前，一眼能看到这个程序有哪些固定值。

**注释里的类型提醒。** 团队合作时，在变量旁标一句单位，能省下很多来回："`float 身高; // 单位：米`"。

**常见坑清单：**

- `int 整 = 3.5;` → 严重错误。要写 `INT(3.5)` 或 `ROUND(3.5)`。
- `char c = "A";` → 严重错误。字符用单引号。
- `string s = 'A';` → 严重错误。字符串用双引号。
- `constant int N = 满分 + 1;`（`满分` 是变量）→ 报"常量必须是能算出来的表达式"。
- 在函数里写 `constant` → 报错，常量只能写在最外层。
- `print 1.0 / 3;` → 得到 `0.333333333333333`，但 `print 1 / 3;` 得到 `0`：两个整数相除是**整数除法**，小数部分直接丢掉。想要小数结果，除号两边至少有一个是小数。

### 本章小结

- 五种类型：`int` 整数、`float` 小数、`string` 字符串、`char` 单字符、`bool` 真假；`none` 只用于函数返回类型。
- 声明格式 `类型 名字 = 初值;`，不写初值自动为 0 / 空 / `false`。
- `constant` 定义常量，只能写在最外层，值必须编译期可算。
- `int` 能自动变 `float`；`float` 变 `int` 必须写 `INT()`（向下）或 `ROUND()`（四舍五入）。
- `print` 输出并换行，`show` 输出不换行，`input 变量;` 读一整行。
- 整数除法会丢小数；小数打印保留 15 位有效数字，比较小数要用误差。

### 学习目标

- 会用 `MOD` 和 `%` 取余，并知道两者规则不同。
- 会用函数库里的数学函数、文本函数和 Excel 风格函数，一个函数能省下好几行循环。
- 知道除零、整数溢出会让程序当场停下。

### 任务引入

超市收银台要一张结算单：输入商品名、单价、数量，打印小计、13% 的税额、合计，还要把合计拆成"整数元"和"零头"。

结算单里全是运算：乘法算小计、百分比算税、取整算零头、四舍五入控制显示位数。做完这个任务，你就能把 Excel 里的公式思路直接搬到程序里。

### 知识准备

#### 3.1 算术运算符

| 运算符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| `+` | 加 | `3 + 4` | `7` |
| `-` | 减 | `10 - 4` | `6` |
| `*` | 乘 | `6 * 7` | `42` |
| `/` | 除 | `17 / 5` | `3`（整数除法，小数丢掉） |
| `%` | 取余 | `17 % 5` | `2` |

有两条必须记住：

- **两个整数相除，结果还是整数**，小数部分直接丢掉，不是四舍五入。`7 / 2` 是 `3`，不是 `3.5`。想要小数结果，让除号两边至少有一个是小数：`7 * 1.0 / 2` 或 `7.0 / 2`。
- **除数是 0 会当场报错并停下**：`C* 运行错误: 除以零`，还会指出是哪个 `.cask` 文件的第几行。

```cask
// 运算符演示
function main() {
    int a = 17;
    int b = 5;
    print "a + b = ", a + b;
    print "a - b = ", a - b;
    print "a * b = ", a * b;
    print "a / b = ", a / b;
    print "a % b = ", a % b;
    print "想要小数：", a * 1.0 / b;
}
```

运行结果：

```text
a + b = 22
a - b = 12
a * b = 85
a / b = 3
a % b = 2
想要小数：3.4
```

#### 3.2 关系运算符

关系运算的结果是 `bool`（真 `true` 或假 `false`）。

| 运算符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| `==` | 等于 | `5 == 5` | `true` |
| `!=` | 不等于 | `5 != 5` | `false` |
| `<` | 小于 | `3 < 5` | `true` |
| `<=` | 小于等于 | `5 <= 5` | `true` |
| `>` | 大于 | `7 > 9` | `false` |
| `>=` | 大于等于 | `7 >= 9` | `false` |

初学者最常见的错误是把 `==` 写成 `=`。`=` 是赋值（把右边的值放进左边的盒子），`==` 才是比较。

#### 3.3 逻辑运算符

| 运算符 | 含义 | 别名 | 说明 |
|--------|------|------|------|
| `and` | 与 | `&&` | 两边都真才是真 |
| `or` | 或 | C 风格写作两条竖线 | 有一边真就是真 |
| `not` | 非 | `!` | 真变假、假变真 |

上面第三列的 C 风格符号在写 C 代码时才会用到；在 `.cask` 里推荐用 `and`、`or`、`not` 这三个词，一眼能看懂。两种写法都能编译，但同一段代码里别混着用。

```cask
// 关系与逻辑
function main() {
    int 分数 = 75;
    print 分数 >= 60;
    print 分数 == 100;
    print 分数 >= 60 and 分数 < 80;
    print 分数 > 90 or 分数 >= 75;
    print not (分数 > 60);
    print IF(分数 >= 60, "及格", "不及格");
}
```

运行结果：

```text
true
false
true
true
false
及格
```

**条件必须是真假的比较结果**，数字不能直接当条件。想表达"非 0 即真"，写清楚：`if (n != 0) { ... }`。

#### 3.4 自增自减与复合赋值

| 写法 | 等价于 | 说明 |
|------|--------|------|
| `i++` | `i = i + 1` | 加 1 |
| `i--` | `i = i - 1` | 减 1 |
| `i += 5` | `i = i + 5` | 加 5 |
| `i -= 5` | `i = i - 5` | 减 5 |
| `i *= 2` | `i = i * 2` | 乘 2 |
| `i /= 4` | `i = i / 4` | 除以 4（整数除法） |
| `i %= 5` | `i = i % 5` | 取余 |

```cask
// 自增与复合赋值
function main() {
    int i = 10;
    print i++;
    print i;
    i += 5;
    print i;
    i -= 2;
    print i;
    i *= 2;
    print i;
    i /= 4;
    print i;
    i %= 5;
    print i;
}
```

运行结果：

```text
10
11
16
14
28
7
2
```

`i++` 用在一句里时是"先用旧值，再加 1"，所以第一行打的是 10，第二行才是 11。写成单独一句 `i++;` 时，就只是"加 1"。

#### 3.5 位运算

位运算按二进制位操作，硬件、编码、压缩题里常见，日常业务用得少。

| 运算符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| `&` | 按位与 | `12 & 10` | `8` |
| `^` | 按位异或 | `12 ^ 10` | `6` |
| `~` | 按位取反 | `~0` | `-1` |
| `<<` | 左移 | `12 << 2` | `48` |
| `>>` | 右移 | `12 >> 1` | `6` |

```cask
// 位运算
function main() {
    int a = 12;    // 二进制 1100
    int b = 10;    // 二进制 1010
    print "按位与 ", a & b;
    print "按位异或 ", a ^ b;
    print "左移两位 ", a << 2;
    print "右移一位 ", a >> 1;
}
```

运行结果：

```text
按位与 8
按位异或 6
左移两位 48
右移一位 6
```

移位位数必须是 0 到 63，左移溢出也会报错，不会悄悄算错。

#### 3.6 优先级

优先级就是从内到外的结合顺序，和数学里"先乘除后加减"是一个道理。

| 从高到低 | 运算符 |
|---------|--------|
| 1 | `()` 括号、`[]` 下标、函数调用 |
| 2 | `not`、负号 `-`、`~`、前缀 `++ --` |
| 3 | `* / %` |
| 4 | `+ -` |
| 5 | `<< >>` |
| 6 | `< <= > >=` |
| 7 | `== !=` |
| 8 | `and` |
| 9 | `or` |
| 10 | `=` 和 `+= -= *= /= %=` |

记不住就加括号。`(a + b) * c` 永远比 `a + b * c` 清楚。

#### 3.7 数学函数（小写，已软弃用）

**`%` 和 `MOD()` 不是一回事。** 两个都存在，规则不同：

| 表达式 | 结果 | 规则 |
|--------|------|------|
| `-3 % 10` | `-3` | C 规则：结果的符号跟着**被除数** |
| `MOD(-3, 10)` | `7` | Excel 规则：结果的符号跟着**除数** |

### 任务实施

任务：做一张超市结算单。

**第 1 步　列出计算口径。**

| 项目 | 公式 |
|------|------|
| 小计 | 单价 × 数量 |
| 税额 | 小计 × 13% |
| 合计 | 小计 + 税额 |
| 整数元 | 合计向下取整 |
| 零头 | 合计 − 整数元 |

税率写成常量，将来改税率只改一行。

**第 2 步　写程序。** 新建 `bill.cask`：

```cask
// bill.cask -- 超市结算单
constant float 税率 = 0.13;

function main() {
    show "商品名称：";
    string 商品;
    input 商品;

    show "单价（元）：";
    float 单价;
    input 单价;

    show "数量：";
    int 数量;
    input 数量;

    float 小计 = 单价 * 数量;
    float 税 = 小计 * 税率;
    float 合计 = 小计 + 税;
    int 整数元 = INT(合计);
    float 零头 = 合计 - 整数元;

    print "=============================";
    print "商品：", 商品;
    print "单价：", 单价, " 元，数量：", 数量;
    print "小计：", ROUND(小计, 2), " 元";
    print "税额（13%）：", ROUND(税, 2), " 元";
    print "合计：", ROUND(合计, 2), " 元";
    print "整数部分 ", 整数元, " 元，零头 ", ROUND(零头, 2), " 元";
    print "=============================";
}
```

**第 3 步　运行并检查结果。** 输入 `笔记本`、`12.5`、`3`：

```text

单价（元）：12.5
数量：3
=============================
商品：笔记本
单价：12.5 元，数量：3
小计：37.5 元
税额（13%）：4.88 元
合计：42.38 元
整数部分 42 元，零头 0.38 元
=============================
```

**第 4 步　手算核对。** 12.5 × 3 = 37.5；37.5 × 0.13 = 4.875，四舍五入两位是 4.88；37.5 + 4.875 = 42.375，四舍五入两位是 42.38，和程序一致。做财务类计算一定要手算核对一次——浮点数的近似误差在小数点上很容易暴露。

### 拓展与规范

**能用函数就别写循环。** 求一列数的总和，`SUM(成绩)` 一行就够；自己写 `for` 累加要四行，还容易写错下标。

**内置函数名不能当变量名。** `SUM`、`LEN`、`MAX`、`IF`、`INT` 这些名字编译器已经占用了，写成变量名会报"是内置函数名"。

**`INT` 是向下取整，不是截断。** `INT(-2.1)` 是 `-3`，不是 `-2`。要"扔掉小数部分"的效果，正数用 `INT` 没问题，负数的行为要自己确认。

**小数结果要控制位数再打印。** 直接把小数打出来是 15 位有效数字，交出去的单据要用 `ROUND(x, 2)`。

**除零和溢出会自动报错。** 这两类错误程序会当场停下并打印 `C* 运行错误: ...`，后面附出错文件的路径和行号。见到这种信息先看行号，直接去那一行找原因。追求速度时可以用 `--fast` 关掉这些检查，但教材里的项目都建议保留检查。

**百分比别写错顺序。** `分数 * 100 / 总分` 和 `分数 / 总分 * 100` 在整数运算下结果可能完全不同：前者先乘再除，通常是对的。

### 本章小结

- 算术运算 `+ - * / %`；整数相除丢小数，除零会报错。
- 关系运算得到 `bool`；`==` 是比较，`=` 是赋值。
- 逻辑运算 `and or not`，别名 `&& || !`；条件必须是比较结果。
- `i++`、`i += 5` 这类写法更短；`i++` 单独成句时就是加 1。
- `%` 结果符号跟被除数，`MOD()` 结果符号跟除数。
- 数学函数、文本函数、Excel 风格函数能省掉大量循环；`SUM/MAX/MIN/COUNT` 传整个数组名。
- 一切能用函数表达的公式，优先用函数，可读性更好。

### 学习目标

- 会用 `switch` 处理"一个值对多个格子"的分支，知道每个 `case` 要写 `break`。
- 会用 `while`、`for`、`do…while`、`until`、`foreach` 五种循环，并知道各自的适用场合。
- 会用 `break` 和 `continue` 控制循环。
- 知道"条件必须是布尔值"这条硬规定，知道 `for (int i = ...)` 的循环变量重复声明会报错。

### 任务引入

老师要一份"期末成绩统计"：不断输入学生成绩，输入 `-1` 结束；结束后打印有效成绩条数、总分、平均分、最高分、最低分、及格率。

这就是典型的"录入 + 统计"程序：录入用循环，合法性检查用判断，统计用累加。程序不会考你先写哪一行，但你自己要知道先搭骨架（循环），再填细节（统计），最后补格式（打印）。

### 知识准备

#### 4.1 if / else if / else

```cask
// 多分支判断
function main() {
    int 分数 = 78;
    if (分数 >= 90) { print "优秀"; }
    else if (分数 >= 80) { print "良好"; }
    else if (分数 >= 70) { print "中等"; }
    else if (分数 >= 60) { print "及格"; }
    else { print "不及格"; }
}
```

运行结果：

```text
中等
```

规则：

- `if` 后面的括号里必须是比较结果（`bool`）。
- 从上到下依次判断，**第一个成立的分支执行后，后面的全部跳过**。所以上面的写法里 `分数 >= 70` 不用再写"且小于 80"，因为到这儿就说明前面两条都不成立。
- `else` 最多一个，写在最后。
- 判断同一个变量的多个区间，`if/else if` 的顺序很重要：**从大到小**排，别把 `>= 60` 写在 `>= 90` 前面。

#### 4.2 switch

当判断条件是"某个整数等于几个固定值之一"时，`switch` 比一串 `else if` 清楚。

```cask
// switch 分档
function main() {
    int 分数 = 95;
    int 档位 = 分数 / 10;
    switch (档位) {
        case 10:
        case 9:  print "优秀"; break;
        case 8:  print "良好"; break;
        case 7:  print "中等"; break;
        case 6:  print "及格"; break;
        default: print "不及格"; break;
    }
}
```

运行结果：

```text
优秀
```

规则：

- `switch` 后面的括号里必须是**整数**（`int`）。
- `case` 后面必须是**编译时能算出值的常量**：字面量、`constant`、四则运算。不能写变量。
- 一个 `case` 后面不写语句，就直接落到下一个 `case`（上面的 `case 10:` 就是这种情况）。
- 每个分支最后要写 `break;` 跳出，不写会继续往下执行别的分支。这是最容易错的细节。
- `default:` 最多一个，可以省略。

#### 4.3 while 和 for

```cask
// 两种最常用的循环
function main() {
    int 总和 = 0;
    int i = 1;
    while (i <= 100) {
        总和 = 总和 + i;
        i++;
    }
    print "1 加到 100 = ", 总和;

    int 阶乘 = 1;
    for (int k = 1; k <= 5; k++) {
        阶乘 = 阶乘 * k;
    }
    print "5! = ", 阶乘;
}
```

运行结果：

```text
1 加到 100 = 5050
5! = 120
```

`for` 括号里是三段，用分号隔开：

| 位置 | 作用 | 常见写法 |
|------|------|----------|
| 第一段 | 初始化，只执行一次 | `int i = 1` |
| 第二段 | 条件，每轮开始前检查 | `i <= 10` |
| 第三段 | 每轮结束后执行 | `i++` |

三段都能省略：`for (;;) { ... }` 就是死循环（要靠 `break` 出来）。

**`for` 的循环变量有个坑。** `for (int i = 0; ...)` 里的 `i` 属于**外层那个大括号的作用域**，不是这个 `for` 私有的。所以在同一层里写两个 `for (int i = ...)` 会报"`i` 已经声明过了"。两种改法：循环变量改用不同的名字；或者先声明 `int i;`，两处都写 `for (i = 0; ...)`；或者给第二个循环套一层 `{ }`。

#### 4.4 do…while 和 until

这两个都是**先做一次，再判断**。

```cask
// 至少执行一次的循环
function main() {
    int n = 10;
    do {
        print "do-while 至少跑一次：n = ", n;
        n++;
    } while (n < 3);

    int m = 0;
    until (m >= 3) {
        print "until 里的 m = ", m;
        m++;
    }
    print "结束，m = ", m;
}
```

运行结果：

```text
do-while 至少跑一次：n = 10
until 里的 m = 0
until 里的 m = 1
until 里的 m = 2
结束，m = 3
```

- `do { } while (条件);` 结尾有分号。条件成立就**继续**。
- `until (条件) { }` 和 `while` 正好相反：条件**成立就停**。适合"一直做到满足要求为止"的说法。
- 两者的循环体都至少执行一次，因为条件是在第一次做完之后才检查的。

#### 4.5 foreach

数组用 `foreach` 遍历最省事，不用管下标：

```cask
// foreach 遍历数组
function main() {
    int 分数[4] = {90, 85, 77, 60};
    int 总 = 0;
    foreach (x in 分数) {
        总 = 总 + x;
        print "本次 ", x, "，累计 ", 总;
    }
    print "平均 ", 总 / 4;
}
```

运行结果：

```text
本次 90，累计 90
本次 85，累计 175
本次 77，累计 252
本次 60，累计 312
平均 78
```

- 写法是 `foreach (变量 in 数组名)`，循环变量前面**不写类型**。写 `foreach (int x in 分数)` 会报错。
- 只支持**一维数组**。二维数组要遍历，用两层 `for`。
- 循环里可以直接改元素的值，改的是数组本身。

#### 4.6 break 和 continue

| 语句 | 作用 |
|------|------|
| `break;` | 立刻跳出**当前这一层**循环 |
| `continue;` | 跳过本轮剩下的语句，直接进入下一轮 |

```cask
// break 与 continue
function main() {
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) { continue; }
        if (i > 7) { break; }
        print i;
    }
}
```

运行结果：

```text
1
3
5
7
```

#### 4.7 五种循环怎么选

| 循环 | 什么时候用 |
|------|-----------|
| `for` | 次数明确，或者要用下标：遍历数组、算阶乘、打表格 |
| `while` | 次数不明确，只知道"满足条件就一直做"：等输入、找满足条件的数 |
| `do…while` | 至少要做一次，做完再看要不要继续：菜单至少要显示一次 |
| `until` | 和 `while` 相反的说法：做到条件成立为止 |
| `foreach` | 只关心每个元素的值，不关心下标 |

### 任务实施

任务：成绩录入与统计。

**第 1 步　想清楚数据。**

| 变量 | 初值 | 说明 |
|------|------|------|
| `分数` | 0 | 当前读入的成绩 |
| `人数` | 0 | 有效成绩条数 |
| `总分` | 0 | 累加 |
| `最高` | -1 | 用一个比任何合法成绩都小的初值 |
| `最低` | 101 | 用一个比任何合法成绩都大的初值 |
| `及格人数` | 0 | 用于算及格率 |

**第 2 步　写程序。** 新建 `scores.cask`：

```cask
// scores.cask -- 录入成绩并统计
function main() {
    int 人数 = 0;
    int 总分 = 0;
    int 最高 = -1;
    int 最低 = 101;
    int 及格人数 = 0;
    int 分数 = 0;

    print "输入成绩（0~100），输入 -1 结束：";
    input 分数;
    while (分数 != -1) {
        if (分数 >= 0 and 分数 <= 100) {
            人数++;
            总分 += 分数;
            if (分数 > 最高) { 最高 = 分数; }
            if (分数 < 最低) { 最低 = 分数; }
            if (分数 >= 60) { 及格人数++; }
        } else {
            print "  不是 0~100 的成绩，已忽略：", 分数;
        }
        input 分数;
    }

    if (人数 == 0) {
        print "没有输入有效成绩。";
    } else {
        print "有效成绩 ", 人数, " 条";
        print "总分 ", 总分, "，平均 ", ROUND(总分 * 1.0 / 人数, 1);
        print "最高 ", 最高, "，最低 ", 最低;
        print "及格率 ", ROUND(及格人数 * 100.0 / 人数, 1), "%";
    }
}
```

**第 3 步　运行并检查。** 依次输入 `90`、`55`、`120`、`78`、`-1`：

```text
输入成绩（0~100），输入 -1 结束：90
55
120
  不是 0~100 的成绩，已忽略：120
78
-1
有效成绩 3 条
总分 223，平均 74.3
最高 90，最低 55
及格率 66.7%
```

**第 4 步　看懂这段程序的骨架。**

- 外层是一个 `while`：只要不是 -1 就继续读。这是"录到哨兵值为止"的标准写法。
- 里层是一个 `if/else`：先判断合法性，再决定统计还是提示。**先校验再使用**，这是数据录入程序的基本纪律。
- 统计放在循环里面，因为每读一条就要累计一次。
- 打印放在循环外面，因为要等录完了才有完整结果。

**第 5 步　试几个边界情况。** 一上来就输入 `-1`，程序应该打印"没有输入有效成绩。"；只输入一个 `100` 再输入 `-1`，平均、最高、最低都应该是 100，及格率 100%。

### 拓展与规范

**判断区间从大到小排。** `if (分数 >= 90) ... else if (分数 >= 80) ...` 这样写，条件互不重叠，不会漏。把顺序写反会出现"所有人都是及格"的荒唐结果。

**`while` 里一定要有让条件变化的语句。** 忘了写 `i++`，程序会一直转，编辑器里按 Esc 才能停。

**`for (;;)` 配上 `break`** 是"不知道要转多少圈"时的常用写法，但 `break` 的条件必须写在显眼的开头。

**`switch` 的 `break` 不能忘。** 忘了写，程序会穿过这个分支继续执行下面的分支。

**`foreach` 只给小名。** 循环变量不写类型；而且它属于外层块，同一层里别再用同名变量。

**输入循环要能退出。** 用户输错格式时 `input` 会要求重输；用哨兵值（比如 -1）结束循环比"输入一个非数字去猜"更可靠。

**先写骨架，再填肉。** 拿到题目先写循环和外层判断，跑一遍看看流程对不对，再往里填统计语句。一次写 30 行再跑，出错很难定位。

### 本章小结

- `if / else if / else` 从大到小排区间；条件必须是 `bool`。
- `switch` 用于整数对若干常量；`case` 后必须是常量，分支末尾写 `break;`。
- `while` 次数不定，`for` 次数明确，`do…while` 和 `until` 至少执行一次，`foreach` 遍历一维数组。
- `for (int i = ...)` 里的 `i` 属于外层作用域，同一层不要重复声明。
- `foreach (x in 数组)` 的循环变量不写类型。
- `break` 跳出本层循环，`continue` 跳过本轮。

## 第 5 章　函数与模块化

### 学习目标

- 会用"返回值类型写在函数名前面"的格式定义函数，会用 `return` 返回结果。
- 会区分有返回值（`int`、`float`、`string`…）和不返回值（`none`、`function`）两种函数。
- 说清参数是"按值传递"的：函数里改参数，外面的变量不变。
- 说清作用域规则，会用全局变量，并知道全局变量必须写在用它的函数前面。
- 会写递归函数，并给它一个能停下来的出口。
- 会用 `use` 引入头文件，知道 C* 目前不能把数组当参数传。

### 任务引入

第 3 章那张结算单只有十来行，但里面所有计算都堆在 `main` 里。现在要加一个"批量结算"功能：一次结算多件商品。如果还堆在 `main` 里改，很容易改坏别的地方。

正确的做法是把"算税""打印金额""画分隔线"这些事各做成一个函数，`main` 只负责把流程串起来。这也是团队分工的基础：把活儿切成几块，一块一个函数。

### 知识准备

#### 5.1 定义函数：返回值类型写在前面

格式是 `返回类型 函数名(参数表) { 函数体 }`：

```cask
// 有返回值的函数
float 平均分(int 总分, int 人数) {
    return 总分 * 1.0 / 人数;
}

string 评级(float 分) {
    if (分 >= 90) { return "优秀"; }
    if (分 >= 60) { return "及格"; }
    return "不及格";
}

function main() {
    int 总分 = 268;
    int 人数 = 3;
    float 平均 = 平均分(总分, 人数);
    print "平均 ", ROUND(平均, 1);
    print "评级 ", 评级(平均);
    print "另一个 ", 评级(95.0);
}
```

运行结果：

```text
平均 89.3
评级 及格
另一个 优秀
```

四条规则：

- **返回值的类型写在函数名前面**，这是 C* 的规定，也是 C 的写法。要返回整数就写 `int`，要返回小数写 `float`，要返回文字写 `string`。
- `return 值;` 一旦执行，函数**立刻结束**，后面的语句不再执行。所以 `评级` 里三个 `return` 只会跑一个。
- 参数表里**每个参数都要写类型**：`(int 总分, int 人数)`，不能只写 `(总分, 人数)`。
- 函数可以**先用后定义**：写在 `main` 后面也行，编译器会先把整个文件扫一遍。

#### 5.2 不返回值的函数

只"做一件事"、不需要交结果的函数，有两种写法，效果一样：

```cask
// 不返回值的函数
none 打横线(int 个数) {
    string 线 = "";
    for (int i = 0; i < 个数; i++) {
        线 = 线 + "-";
    }
    print 线;
}

function 打印标题(string 标题) {
    print "=== ", 标题, " ===";
}

function main() {
    打横线(20);
    打印标题("成绩单");
    打横线(20);
}
```

运行结果：

```text
--------------------
=== 成绩单 ===
--------------------
```

- 写 `none` 开头的函数不能 `return 值;`，但可以写 `return;` 提前结束。
- 写 `function` 开头的函数同样不返回值。两种写法完全等价，本书统一用 `none` 表示"不返回值的函数"，用 `function main()` 表示入口。

#### 5.3 参数是按值传的

调用函数时，参数的值被**复制一份**送进去。函数里改的是那份拷贝，外面的变量不受影响。

```cask
// 参数是按值传递的
none 改一改(int x) {
    x = x * 10;
    print "函数里面 x = ", x;
}

function main() {
    int n = 5;
    print "调用前 n = ", n;
    改一改(n);
    print "调用后 n = ", n;
}
```

运行结果：

```text
调用前 n = 5
函数里面 x = 50
调用后 n = 5
```

想让函数"改外面的东西"，用 `return` 把结果交回去，再在外面赋值：

```cask
// 通过返回值把结果交回去
function main() {
    int n = 5;
    n = 加十倍(n);
    print "n = ", n;
}

int 加十倍(int x) {
    return x * 10;
}
```

运行结果：

```text
n = 50
```

#### 5.4 作用域

| 名字写在哪 | 谁能看见 |
|-----------|----------|
| 函数里的 `{ }` 中 | 只在那个 `{ }` 里看得见，出了大括号就没了 |
| 所有函数外面（最外层） | 这叫全局变量，**写在它前面**的所有函数都能读写 |

```cask
// 全局变量与局部变量
int 累计 = 0;                     // 全局变量：写在最外层

none 记一笔(int 金额) {
    累计 = 累计 + 金额;            // 函数里可以直接改全局变量
    print "这一笔 ", 金额, "，累计 ", 累计;
}

function main() {
    记一笔(100);
    记一笔(50);
    print "总计 ", 累计;
}
```

运行结果：

```text
这一笔 100，累计 100
这一笔 50，累计 150
总计 150
```

两个容易踩的地方：

- **全局变量要写在用它的函数前面。** 把 `int 累计 = 0;` 挪到文件最后，程序编译不过。C* 生成 C 时是按顺序排的，和 C 的规则一样。
- **内层可以起和外层一样的名字**，内层的会"遮住"外层的。这不是好习惯，正式项目里尽量避免。

#### 5.5 递归：函数自己叫自己

函数体里调用自己叫递归。递归必须有**出口**，否则会一直往下叫。

```cask
// 递归求阶乘
int 阶乘(int n) {
    if (n <= 1) { return 1; }
    return n * 阶乘(n - 1);
}

function main() {
    for (int i = 1; i <= 6; i++) {
        print i, "! = ", 阶乘(i);
    }
}
```

运行结果：

```text
1! = 1
2! = 2
3! = 6
4! = 24
5! = 120
6! = 720
```

写递归时先写出口（`if (n <= 1) { return 1; }`），再写"把问题缩小一步"的那句，顺序不要倒。

#### 5.6 数组暂时不能当参数

C* 0.4.2 里**函数参数不能是数组**。写下 `int 求和(int 数据[4])` 会直接报错：

```text
错误: 还不支持数组参数（v0.1）
```

替代办法有三个：

- 用内置的汇总函数：`SUM(数组)`、`AVERAGE(数组)`、`MAX(数组)`、`MIN(数组)`、`COUNT(数组)`。
- 把数组写成**全局变量**，函数里直接按名字访问。
- 把循环写在调用处，不封成函数。

```cask
// 用全局数组代替"数组参数"
int 分数[5] = {88, 95, 72, 66, 91};

float 平均() {
    return AVERAGE(分数);
}

function main() {
    print "本班平均 ", 平均();
    print "本班最高 ", MAX(分数);
}
```

#### 5.7 use：把 C 的头文件引进来

`use` 做的事就是 C 的 `#include`：把另一个文件的内容包含进程序。

```cask
use "my_lib.h";                 // 引号：先在本目录（exe 所在目录）找
use <stdio.h>;                  // 尖括号：在编译器自带的系统目录里找
```

尖括号引的是系统头文件。引号引的是自己写的头文件，放在 `.cask` 旁边即可——因为不带 `-o` 时，生成的 exe 就在 `.cask` 同一个目录里。

自己写的头文件里可以放函数。要让编译器认得出里面那个函数，需要在 `.cask` 里补一行**函数原型**，参数类型要写得和 C 一致：`int` 对应 C 的 `long long`。

```cask
use "my_lib.h";                 // 先把头文件引进来

int double_it(int x);           // 再声明头文件里那个函数的原型
```

配套的 `my_lib.h` 内容：

```c
/* my_lib.h -- 自己写的小工具头文件 */
static long long double_it(long long x) { return x * 2; }
```

在程序里就可以像自己的函数一样调用 `double_it(21)`，结果是 42。

三条要注意的：

- 头文件里的函数**必须先声明原型再调用**。忘了写，编译器会提示 `不认识的函数 ...（如果它来自 'use' 的头文件，请先声明: int ...(...);）`，照着提示补一行就行。
- 头文件里的 `#define` 宏**不能直接当变量名用**。要固定的值，在自己的 `.cask` 里写 `constant`。
- 头文件路径是相对**生成的 exe** 的目录算的。用了 `-o 别的目录\程序.exe`，头文件也要放到那个目录里。

系统头文件里的函数怎么用，第 10 章会用完整的例子讲（那一章还要引 `C_OPED.cash`）。

任务：把第 3 章的结算单改成函数版，并支持批量结算。

**第 1 步　列出可以拆成函数的活儿。**

| 函数 | 干什么 | 返回值 |
|------|--------|--------|
| `分隔线()` | 打印一行等号 | 无（`none`） |

**第 2 步　写程序。** 新建 `bill2.cask`：

```cask
// bill2.cask -- 结算单（函数版）
constant float 税率 = 0.13;
constant int 行宽 = 29;

none 分隔线() {
    string 线 = "";
    for (int i = 0; i < 行宽; i++) {
        线 = 线 + "=";
    }
    print 线;
}

float 读小数(string 提示) {
    show 提示;
    float 值;
    input 值;
    return 值;
}

int 读整数(string 提示) {
    show 提示;
    int 值;
    input 值;
    return 值;
}

float 算税(float 小计) {
    return 小计 * 税率;
}

none 打印金额(string 名称, float 金额) {

function main() {

    分隔线();

    打印金额("小计：", 小计);
    打印金额("税额（13%）：", 税);
    打印金额("合计：", 小计 + 税);

```

**第 3 步　运行并检查。** 输入 `笔记本`、`12.5`、`3`：

```text

数量：3

```

**第 4 步　对照两版代码。** 功能一模一样，但函数版的 `main` 只有 14 行，读起来就是一张流程清单：读商品 → 读单价 → 读数量 → 算小计 → 算税 → 打印。要改税率只改常量，要改打印格式只改 `打印金额`，要改分隔线长度只改 `行宽`。

### 拓展与规范

**函数名用动词或动宾短语。** `算税`、`打印金额`、`读整数` 一看就知道干什么。`f1`、`abc` 这种名字，三天后自己也看不懂。

**一个函数只做一件事。** 既读数据又算结果又打印的函数，没法复用也没法测。拆开以后，`算税` 可以单独拿去做单元测试。

**参数别超过四五个。** 参数太多说明这个函数管的事太杂，该拆了。

**在函数上方写一行注释**，写清参数含义和返回值，尤其是单位：

```cask
// 按税率算税；小计单位：元；返回税额，单位：元
float 算税(float 小计) {
    return 小计 * 税率;
}
```

**全局变量能少用就少用。** 全局变量谁都能改，出了问题很难查。真正需要共享的数据（比如成绩数组）再用。

**记得 `return`。** 声明了返回类型却忘了 `return`，编译器会在函数末尾补一个安全的 `return 0`，程序不会崩，但结果会是 0——排查起来反而更费劲。

**返回类型要对上。** `int` 的函数里 `return 3.5;` 会报类型不符，要写 `return INT(3.5);`。

**调用时参数个数和顺序要一致。** 少给一个参数、把小数传给 `int` 参数，都会报严重错误。

**别把 `=` 当比较用。** `if (x = 5)` 不是判断，编译器会拦下来（`=` 不能出现在条件里）。

### 本章小结

- 定义格式：`返回类型 函数名(参数表) { ... }`，用 `return` 交结果；不返回值用 `none` 或 `function` 开头。
- 参数按值传递，函数里改参数不影响外面；要"改外面"就用返回值。
- 局部变量出了 `{ }` 就失效；全局变量写在最外层，而且必须在用它之前。
- 递归要有出口，先写出口再写递归调用。
- 函数里不能传数组，用 `SUM/AVERAGE/MAX/MIN/COUNT` 或者把数组放全局。
- `use "头文件.h";` 相当于 C 的 `#include`；引用自定义头文件里的函数要先写函数原型。

## 第 6 章　数组与字符串处理

### 学习目标

- 会声明、初始化、读写下标的一维数组和二维数组，知道下标从 0 开始。
- 会说清数组越界会让程序当场报错，并会看那条错误信息。
- 会用 `for` 和 `foreach` 遍历数组，会用内置汇总函数做统计。
- 会写冒泡排序和顺序查找。
- 会用文本函数处理字符串，知道 `string` 不能原地改一个字符，知道中文一个字占 3 个字节。

### 任务引入

期末要交一份成绩单：老师给一份"姓名 + 分数"的名单，要求按分数从高到低排出来，并算出总分、平均、最高、最低、及格率，最后还要能按姓名查一个人的分数。

这是数组练习的标准题：一个 `string` 数组存姓名，一个 `int` 数组存分数，两个数组**下标对齐**（第 3 个姓名配第 3 个分数）。排序时两个数组要一起换，这是本题最容易出错的地方。

### 知识准备

#### 6.1 一维数组

```cask
// 数组的声明、初始化、读写
function main() {
    int 分数[5] = {90, 80, 70, 60, 50};
    print "第 1 个 ", 分数[0];
    print "第 5 个 ", 分数[4];
    print "元素个数 ", COUNT(分数);

    分数[2] = 75;
    print "改过以后第 3 个 ", 分数[2];

    int 空白[4];
    print "没写初值自动为 0：", 空白[0], " ", 空白[3];
}
```

运行结果：

```text
第 1 个 90
第 5 个 50
元素个数 5
改过以后第 3 个 75
没写初值自动为 0：0 0
```

规则：

- 声明格式 `类型 名字[长度];`，长度必须是整数或常量。
- `int 分数[5];` 的下标是 **0 到 4**，没有 `分数[5]`。
- 用 `= {…}` 一次给出全部初值；给一部分不行（个数要么全给，要么不写）。
- 不写初值，**所有元素自动为 0**（`string` 数组的元素自动为空文字）。
- 下标越界（`分数[5]`、`分数[-1]`）会当场报错：`C* 运行错误: 数组下标越界`。

#### 6.2 遍历：for 和 foreach

```cask
// 两种遍历方式
function main() {
    int 分数[6] = {72, 95, 60, 88, 95, 77};

    int 总 = 0;
    int 最高 = 分数[0];
    for (int i = 0; i < 6; i++) {
        总 += 分数[i];
        if (分数[i] > 最高) { 最高 = 分数[i]; }
    }
    print "总分 ", 总;
    print "平均 ", ROUND(总 * 1.0 / 6, 1);
    print "最高 ", 最高;

    print "依次列出：";
    foreach (x in 分数) {
        show x, " ";
    }
    print "";
}
```

运行结果：

```text
总分 487
平均 81.2
最高 95
依次列出：
72 95 60 88 95 77 
```

要**下标**（比如"改第 3 个"、"找位置"）就用 `for`；只关心**值**就用 `foreach`。

同样这几件事，内置函数一行就够，可以拿来核对：

```cask
// 内置汇总函数对照
function main() {
    int 分数[6] = {72, 95, 60, 88, 95, 77};
    print "总和 ", SUM(分数);
    print "平均 ", AVERAGE(分数);
    print "最高 ", MAX(分数);
    print "最低 ", MIN(分数);
    print "个数 ", COUNT(分数);
}
```

运行结果：

```text

平均 81.1666666666667
最高 95
最低 60

```

注意 `AVERAGE` 返回的是**没取位的小数**，要交单据还得套一层 `ROUND`。另外 `SUM/AVERAGE/MAX/MIN/COUNT` 只能用在**一维数组**上。

#### 6.3 二维数组

```cask
// 二维数组：3 个学生 × 2 门课
function main() {
    int 成绩[3][2] = {{90, 85}, {70, 66}, {88, 92}};
    for (int i = 0; i < 3; i++) {
        int 总 = 0;
        for (int j = 0; j < 2; j++) {
            总 += 成绩[i][j];
        }
        print "学生 ", i + 1, " 总分 ", 总, "，平均 ", ROUND(总 * 1.0 / 2, 1);

}
```

运行结果：

```text

学生 2 总分 136，平均 68
学生 3 总分 180，平均 90
```

`成绩[i][j]` 里，第一个下标是行（学生），第二个是列（课程）。最多支持 8 维，但实际项目里两层就够。

#### 6.4 排序：冒泡排序

思路：从第一个元素开始，相邻两个比大小，大的往后换；走完一趟，最大的就"冒"到了最后。重复若干趟，全部有序。

```cask
// 冒泡排序：从小到大
function main() {
    int 分数[6] = {72, 95, 60, 88, 95, 77};
    for (int i = 0; i < 5; i++) {
        for (int j = 0; j < 5 - i; j++) {
            if (分数[j] > 分数[j + 1]) {
                int 临时 = 分数[j];
                分数[j] = 分数[j + 1];
                分数[j + 1] = 临时;
            }
        }
    }
    foreach (x in 分数) { show x, "  "; }
    print "";
}
```

运行结果：

```text
60  72  77  88  95  95  
```

外层要从大到小排，把 `>` 改成 `<` 即可。交换两个值必须先存到临时变量里，写成 `分数[j] = 分数[j + 1]; 分数[j + 1] = 分数[j];` 会把第一个值覆盖掉。

#### 6.5 查找：顺序查找

```cask
// 顺序查找
function main() {
    int 分数[6] = {72, 95, 60, 88, 95, 77};
    int 目标 = 88;
    int 位置 = -1;
    for (int i = 0; i < 6; i++) {
        if (分数[i] == 目标) {
            位置 = i;
            break;
        }
    }
    if (位置 >= 0) {
        print "找到 ", 目标, "，下标 ", 位置, "，是第 ", 位置 + 1, " 个";
    } else {
        print "没找到 ", 目标;
    }
}
```

运行结果：

```text
找到 88，下标 3，是第 4 个
```

用 `位置 = -1` 表示"还没找到"，是这类程序的通用写法：真找到了就赋成真实下标（一定大于等于 0），最后用 `位置 >= 0` 判断。

#### 6.6 字符串处理

`string` 是一串文字。它**不能被原地修改**，所有"改"都靠拼出新字符串。

```cask
// 字符串处理
function main() {
    string 姓名 = "  li ming  ";
    string 干净 = TRIM(姓名);
    print "去空格 '", 干净, "'";
    print "长度 ", LEN(干净);
    print "大写 ", UPPER(干净);
    print "首字母 ", LEFT(UPPER(干净), 1);

    string 学号 = "2024012301";
    print "年级 ", LEFT(学号, 4), "，班号 ", MID(学号, 5, 2), "，序号 ", RIGHT(学号, 4);
    print "拼接 ", CONCAT(干净, "@school.cn");
    print "相等比较 ", 干净 == "li ming";
    print "字典序 ", "abc" < "abd";
    print "第 2 个字符 ", at(干净, 1);
}
```

运行结果：

```text
去空格 'li ming'
长度 7
大写 LI MING
首字母 L
年级 2024，班号 01，序号 2301
拼接 li ming@school.cn
相等比较 true
字典序 true
第 2 个字符 i
```

- 字符串可以直接用 `+` 连接，也可以和数字、真假混着拼：`"总分 " + 总` 得到一段文字。
- `==`、`<` 这些比较符对字符串也有效，`==` 比的是**内容**，不是地址。字典序按字符编码比，`"abc" < "abd"` 是因为 `c` 在 `d` 前面。
- `at(文字, 下标)` 取一个字符（下标从 0 开始）；`LEFT/RIGHT/MID` 取子串，位置从 1 开始（Excel 习惯）。两套习惯不一样，别记混。

#### 6.7 中文：一个字占 3 个字节

`LEN`、`LEFT`、`MID`、`at` 数的都是**字节**。UTF-8 编码下，一个汉字占 3 个字节。

```cask
// 中文的长度按字节算
function main() {
    string 词 = "中文ABC";
    print "长度 ", LEN(词), "（一个汉字 3 个字节）";
    string 前三个 = LEFT(词, 3);
    print "LEFT(词,3) 得到 '", 前三个, "'，它的长度 ", LEN(前三个);
    print "只取 1 个字节会切碎汉字，长度 ", LEN(LEFT(词, 1));
}
```

运行结果：

```text
长度 9（一个汉字 3 个字节）
LEFT(词,3) 得到 '中'，它的长度 3
只取 1 个字节会切碎汉字，长度 1
```

所以对中文做取子串，要么按 3 的倍数取，要么干脆别取——`LEN("中文")` 是 6 不是 2，这个数字只适合用来算"占了多少字节"。

### 拓展与规范

**下标从 0 开始，长度是"个数"。** `int a[5]` 的合法下标是 0 到 4。写循环用 `i < 5`，别写 `i <= 5`。

**长度用常量。** 把 `50` 写成 `constant int 最多人数 = 50;`，以后要改只改一处，长度和循环条件都跟着改。

**`for` 的循环变量重复声明会报错。** 原文是 `'i' 在这里已经声明过了`。三种改法：起不同的名字、先声明后用 `for (i = 0; ...)`、或者给第二个循环套一层 `{ }`。

**`foreach` 的循环变量不写类型。** 写 `foreach (int x in 数组)` 会报"这里要写循环变量名"。

**排序时"一起换"。** 姓名和分数是两个数组，交换分数时必须同时交换姓名，否则名单和分数会对不上。这类"平行数组"是数组入门阶段的常态。

**越界的错误信息很直白。** 见到 `C* 运行错误: 数组下标越界`，去信息里给的行号，检查那一行的下标表达式。常见原因是循环用了 `<=`，或者下标是算出来的、算大了。

**字符串拼接在循环里要小心效率。** 一次拼几百个字符没问题；拼几万次会很慢。数据量大时改用 `memo` 一次性输出。

**中英混排的宽度。** `LEN("中文A")` 是 7（3+3+1），不是 3。要按"显示宽度"排版，得自己把汉字按 2 个宽度算。

### 本章小结

- 数组 `类型 名字[长度];` 或 `类型 名字[长度] = {…};`，下标从 0 到长度减 1，越界会报错。
- 不写初值时所有元素自动为 0（`string` 为空文字）。
- `for` 要下标，`foreach` 只取值（循环变量不写类型，只支持一维数组）。
- `SUM/AVERAGE/MAX/MIN/COUNT` 传一维数组名，省掉手写循环。
- 冒泡排序：相邻比较、交换，外层轮数 `长度-1`；交换必须用临时变量。
- 顺序查找：用 `位置 = -1` 表示没找到。
- 字符串用 `+` 或 `CONCAT` 拼接，`==` 比内容，`LEN/LEFT/MID/at` 按字节计数，一个汉字 3 个字节。

### 任务引入

**需求说明（来自教务处的口头需求）：**

> 一个班最多 50 人，每人有学号、姓名、3 门课成绩。教师需要一个能在机房电脑上直接跑的小程序，能录入、能看总表、能统计班级情况、能按平均分排序、能按学号或姓名查人。界面简单点没关系，但**不能出错**。

这份需求可以拆成五个功能加一个菜单：

| 编号 | 功能 | 输入 | 输出 |
|------|------|------|------|
| 1 | 录入 | 学号、姓名、3 门课成绩 | 确认信息和平均分 |

### 知识准备

#### 7.1 菜单循环的骨架

菜单程序的结构就是"打印菜单 → 读一个选择 → 分支处理 → 回到开头"。用一个 `while` 加一个 `if/else if` 链就够。

```cask
// 菜单循环的骨架（用数组模拟"用户依次输入的选择"）
function main() {
    int 选择[5] = {1, 3, 9, 2, 0};
    for (int i = 0; i < 5; i++) {
        int 当前 = 选择[i];
        print "1 录入  2 显示  0 退出";
        print "请选择：", 当前;
        if (当前 == 1) { print "  你选了录入"; }
        else if (当前 == 2) { print "  你选了显示"; }
        else if (当前 == 0) { print "  再见"; }
        else { print "  没有这个选项"; }
        if (当前 == 0) { break; }
    }
}
```

运行结果：

```text
1 录入  2 显示  0 退出
请选择：1
  你选了录入
1 录入  2 显示  0 退出
请选择：3
  没有这个选项
1 录入  2 显示  0 退出
请选择：9
  没有这个选项
1 录入  2 显示  0 退出
请选择：2
  你选了显示
1 录入  2 显示  0 退出
请选择：0
  再见
```

真实程序里把 `选择[i]` 换成 `input 选择;` 就是完整菜单。所以 `main` 会长成这样：

```cask
int 选择 = -1;
while (选择 != 0) {
    print "1 录入  2 显示  0 退出";
    show "请选择：";
    input 选择;
    if (选择 == 1) { 录入(); }
    else if (选择 == 2) { 显示(); }
    else if (选择 == 0) { print "再见。"; }
    else { print "没有这个选项。"; }
}
```

`选择` 初值给 -1，是为了保证第一次判断 `选择 != 0` 一定成立。

#### 7.2 数据放在哪：全局数组

函数不能接收数组，所以名单数据只能是**全局数组**，所有函数按名字直接访问：

| 数组 | 类型 | 存什么 |
|------|------|--------|
| `学号` | `string[50]` | 学号，下标 i 是第 i+1 个学生 |
| `姓名` | `string[50]` | 姓名 |
| `成绩` | `int[50][3]` | 3 门课成绩，`成绩[i][j]` |
| `平均` | `float[50]` | 平均分，录入时算好，排序时一起换 |
| `人数` | `int` | 当前实际录了几个 |

**只要有一个数组跟着排序动，其他几个必须一起动。** 这是本项目最大的技术点：

```cask
// 三个平行数组一起换
string 姓名[4] = {"甲", "乙", "丙", "丁"};
int 分数[4] = {70, 90, 80, 60};
float 平均[4] = {70.0, 90.0, 80.0, 60.0};

function main() {
    int i;
    for (i = 0; i < 3; i++) {
        for (int j = 0; j < 3 - i; j++) {
            if (平均[j] < 平均[j + 1]) {
                string 临时名 = 姓名[j]; 姓名[j] = 姓名[j + 1]; 姓名[j + 1] = 临时名;
                int 临时分 = 分数[j]; 分数[j] = 分数[j + 1]; 分数[j + 1] = 临时分;
                float 临时均 = 平均[j]; 平均[j] = 平均[j + 1]; 平均[j + 1] = 临时均;
            }
        }
    }
    for (i = 0; i < 4; i++) {
        print i + 1, ". ", 姓名[i], " ", 分数[i], " ", 平均[i];
    }
}
```

运行结果：

```text
1. 乙 90 90
2. 丙 80 80
3. 甲 70 70
4. 丁 60 60
```

把交换那三组语句抽成一个 `交换(a, b)` 函数，排序函数就干净了。

#### 7.3 平均分要在录入时就算好

排序和统计都要用平均分，每次现算很浪费。在录入结束时算好存进 `平均` 数组，后面所有函数直接用。

```cask
none 算平均(int k) {
    int 总 = 0;
    for (int j = 0; j < 课程数; j++) {
        总 += 成绩[k][j];
    }
    平均[k] = 总 * 1.0 / 课程数;
}
```

`总 * 1.0` 是把整数转成小数再除，否则整数除法会把小数部分丢掉。

#### 7.4 输入函数单独封装

`input` 只能读进一个已经声明好的变量，所以"显示提示 + 读一行"这两步在项目里会出现很多次，封装成两个函数：

```cask
string 读文字(string 提示) {
    show 提示;
    string s;
    input s;
    return s;
}

int 读整数(string 提示) {
    show 提示;
    int n;
    input n;
    return n;
}
```

以后想改成"提示后面加个冒号"，只改这两处。

```cask
    show 提示;

    input n;

    if (分 >= 90) { return "优秀"; }
    if (分 >= 80) { return "良好"; }
    if (分 >= 70) { return "中等"; }
    if (分 >= 60) { return "及格"; }
    return "不及格";

none 算平均(int k) {
    int 总 = 0;
    for (int j = 0; j < 课程数; j++) {
        总 += 成绩[k][j];
    }
    平均[k] = 总 * 1.0 / 课程数;
}

none 录入() {
    if (人数 >= 最多) { print "名单已满。"; return; }
    int k = 人数;
    学号[k] = 读文字("学号：");
    姓名[k] = 读文字("姓名：");
    for (int j = 0; j < 课程数; j++) {
        成绩[k][j] = 读整数(CONCAT("第 ", j + 1, " 门课成绩："));
    }
    算平均(k);
    人数++;
    print "已录入 ", 姓名[k], "，平均 ", ROUND(平均[k], 1);
}

none 显示() {
    if (人数 == 0) { print "还没有数据。"; return; }
    print "---- 共 ", 人数, " 人 ----";
    for (int i = 0; i < 人数; i++) {
        print i + 1, ". ", 学号[i], " ", 姓名[i], " 平均 ", ROUND(平均[i], 1), " 等级 ", 等级(平均[i]);
    }
}

none 交换(int a, int b) {
    string 临时号 = 学号[a]; 学号[a] = 学号[b]; 学号[b] = 临时号;
    string 临时名 = 姓名[a]; 姓名[a] = 姓名[b]; 姓名[b] = 临时名;
    for (int j = 0; j < 课程数; j++) {
        int 临时分 = 成绩[a][j]; 成绩[a][j] = 成绩[b][j]; 成绩[b][j] = 临时分;
    }
    float 临时均 = 平均[a]; 平均[a] = 平均[b]; 平均[b] = 临时均;
}

none 排序() {
    if (人数 < 2) { print "人太少，不用排。"; return; }
    for (int i = 0; i < 人数 - 1; i++) {
        for (int j = 0; j < 人数 - 1 - i; j++) {
            if (平均[j] < 平均[j + 1]) { 交换(j, j + 1); }
        }
    }
    print "已按平均分从高到低排好。";
}

none 统计() {
    if (人数 == 0) { print "还没有数据。"; return; }
    float 总和 = 0;
    float 最高 = 平均[0];
    float 最低 = 平均[0];
    int 优秀 = 0; int 良好 = 0; int 中等 = 0; int 及格 = 0; int 不及格 = 0;
    for (int i = 0; i < 人数; i++) {
        总和 += 平均[i];
        if (平均[i] > 最高) { 最高 = 平均[i]; }
        if (平均[i] < 最低) { 最低 = 平均[i]; }
        if (平均[i] >= 90) { 优秀++; }
        else if (平均[i] >= 80) { 良好++; }
        else if (平均[i] >= 70) { 中等++; }
        else if (平均[i] >= 60) { 及格++; }
        else { 不及格++; }
    }
    print "人数 ", 人数;
    print "班级平均 ", ROUND(总和 / 人数, 2);
    print "最高 ", ROUND(最高, 1), "，最低 ", ROUND(最低, 1);
    print "等级分布：优秀 ", 优秀, "，良好 ", 良好, "，中等 ", 中等, "，及格 ", 及格, "，不及格 ", 不及格;
}

none 查找() {
    string 目标 = 读文字("要查的学号或姓名：");
    int 位置 = -1;
    for (int i = 0; i < 人数; i++) {
        if (学号[i] == 目标 or 姓名[i] == 目标) { 位置 = i; break; }
    }
    if (位置 >= 0) {
        print 学号[位置], " ", 姓名[位置], " 各门 ", 成绩[位置][0], " ", 成绩[位置][1], " ", 成绩[位置][2],
              " 平均 ", ROUND(平均[位置], 1), " 等级 ", 等级(平均[位置]);
    } else {
        print "没找到 ", 目标;
    }
}

function main() {
    print "=== 学籍成绩统计 v1.0 ===";
    int 选择 = -1;
    while (选择 != 0) {
        print "1 录入  2 显示  3 统计  4 排序  5 查找  0 退出";
        show "请选择：";
        input 选择;
        if (选择 == 1) { 录入(); }
        else if (选择 == 2) { 显示(); }
        else if (选择 == 3) { 统计(); }
        else if (选择 == 4) { 排序(); }
        else if (选择 == 5) { 查找(); }
        else if (选择 == 0) { print "再见。"; }
        else { print "没有这个选项。"; }
    }
}
```

## 第 8 章　窗口程序入门

### 学习目标

- 会写一个能开窗口、有按钮、能响应点击的程序。
- 说清 `use "C_OPED.cash";` 这一行做了什么。
- 会用 `window`、`label`、`button` 三个函数，会安排控件的坐标和大小。
- 会写 `on_click` 事件函数，并用控件号区分是哪个按钮被点了。
- 知道窗口程序怎么编译、怎么调试、运行时会看到什么。

### 任务引入

机房点名要一个"签到计数器"：点一下按钮人数加一，点错了能撤销，还能清零。要求是**窗口界面**，不是黑屏命令行——因为使用者是不懂电脑的老师。

从这一章开始，C* 程序不再只往上滚文字，而是能开真正的 Windows 窗口。做法只有一行：程序第一行写 `use "C_OPED.cash";`。

### 知识准备

#### 8.1 第一行：打开窗口和 C 的世界

```cask
use "C_OPED.cash";
```

这一行是 C* 的"总开关"，它一次做了四件事：

| 做的事 | 效果 |
|--------|------|
| 引入窗口头文件 | 后面就能用 `window`、`label`、`button` 这些函数 |
| 自动链接窗口库 | 不用自己写链接参数 |
| 打开 C / C++ / Win32 世界 | 第 10 章要用：直接调用 `MessageBoxA`、`GetTickCount` 等函数 |
| 把生成的程序变成 Windows 图形程序 | 编译出来是 `WinMain` 入口，运行时**没有黑色控制台窗口** |

这一行必须在文件最前面。有了它，程序里就**不需要**再写任何 `include`。

#### 8.2 开一个窗口

```cask
int 窗口 = window("窗口标题", 宽, 高);
```

三个参数分别是标题文字、宽度、高度，单位是像素。返回值是"窗口号"，要留着后面用。

```cask
use "C_OPED.cash";

function main() {
    int 窗口 = window("我的第一个窗口", 460, 260);
    label("你好，窗口！", 24, 24, 400, 24);
    run();
}
```

这个程序编译运行后，屏幕上会出现一个 460×260 的窗口，标题是"我的第一个窗口"，窗口里靠左上角有一行字"你好，窗口！"。窗口**一直显示着**，直到你点右上角的关闭按钮。

`run();` 是"进入事件循环"：程序停在这里，等用户点按钮、打字、关窗口。窗口关掉之后 `run()` 才返回，`main` 结束，程序退出。

#### 8.3 往窗口里放控件

控件的添加函数格式统一是 `(文字, x, y, 宽, 高)`：

| 函数 | 放什么 | 参数 |
|------|--------|------|
| `label(文字, x, y, 宽, 高)` | 一行文字（不能改的那种"标签"） | 5 个 |
| `button(文字, x, y, 宽, 高)` | 按钮 | 5 个 |
| `textbox(文字, x, y, 宽, 高)` | 单行输入框 | 5 个 |
| `memo(文字, x, y, 宽, 高)` | 多行输入框 | 5 个 |
| `checkbox(文字, x, y, 宽, 高)` | 复选框 | 5 个 |
| `listbox(x, y, 宽, 高)` | 列表 | 4 个（没有文字） |
| `progress(x, y, 宽, 高)` | 进度条 | 4 个（没有文字） |

坐标 `x`、`y` 的原点在窗口**客户区左上角**（也就是标题栏下面那块空白区域的左上角），向右是 x 增大，向下是 y 增大，单位是像素。

每个控件都会返回一个"控件号"（一个整数）。**要读它、改它的控件，必须把控件号存起来。**

**一个程序只调用一次 `window()`。** 后面添加的控件全都加进第一个窗口。

#### 8.4 按钮被点了怎么办：on_click

```cask
function on_click(int 控件) {
    // 控件 就是被点击的那个控件的编号
}
```

这个名字是**固定**的。只要程序里定义了这个函数，用户点任何按钮都会自动调用它，参数是被点控件的编号。所以：

- 需要一个全局变量保存按钮的编号，事件函数里才能比较。
- 用 `if (控件 == 某个按钮)` 判断是哪一个。

```cask
use "C_OPED.cash";

int 显示框;
int 次数 = 0;

function on_click(int 控件) {
    次数 = 次数 + 1;
    settext(显示框, "你点了 " + 次数 + " 次");
}

function main() {
    int 窗口 = window("按钮计数器", 480, 300);
    label("点下面的按钮，看看数字怎么变：", 24, 24, 420, 24);
    显示框 = label("你点了 0 次", 24, 56, 420, 24);
    int 按钮 = button("点我", 24, 100, 140, 34);
    run();
}
```

`settext(控件, "文字")` 用来改控件上显示的文字。这个程序换成真实的运行效果就是：窗口里有两行文字和一个"点我"按钮，每点一次按钮，第二行文字就变成"你点了 1 次"、"你点了 2 次"……

#### 8.5 多个按钮怎么区分

```cask
use "C_OPED.cash";

int 显示框;
int 加按钮;
int 减按钮;
int 计数 = 0;

none 刷新() {
    settext(显示框, "当前计数 " + 计数);
}

function on_click(int 控件) {
    if (控件 == 加按钮) { 计数 = 计数 + 1; }
    if (控件 == 减按钮) { 计数 = 计数 - 1; }
    刷新();
}

function main() {
    int 窗口 = window("加减计数", 480, 300);
    显示框 = label("当前计数 0", 24, 24, 420, 24);
    加按钮 = button("+1", 24, 80, 100, 34);
    减按钮 = button("-1", 140, 80, 100, 34);
    刷新();
    run();
}
```

要点：

- **三个控件的编号都存进了全局变量**。如果 `加按钮` 写成 `main` 里的局部变量，`on_click` 里就看不见它，没法比较。
- 把"更新界面"抽成 `刷新()`，两处按钮都调用它，界面不会出现两套写法不一致的情况。
- 在 `run()` 之前先调一次 `刷新()`，保证窗口一出现就是正确状态。

#### 8.6 编译和运行

窗口程序的编译命令和以前一样：

```bat
bin\caskc.exe 签到.cask -o 签到.exe --run
```

几点不同：

| 情况 | 说明 |
|------|------|
| 没有黑控制台 | 窗口程序编译时按图形程序链接，双击 exe 只出现窗口 |
| 想看 `print` 的输出 | 编译时加 `--console`，会保留黑控制台窗口，`print` 的内容显示在那里 |
| 调试 | 加 `-g` 生成带调试信息的版本，出错时更容易定位 |
| 出错想看提示 | `alert("内容")` 弹一个消息框，比 `print` 直观（见第 9 章） |

窗口程序在编辑器里按 F5 一样能跑。程序会一直运行到窗口被关掉，想强制结束按 Esc。

```cask
// sign.cask -- 签到计数器（窗口程序）
use "C_OPED.cash";

int 提示标签;
int 状态标签;
int 签到按钮;
int 撤销按钮;
int 清零按钮;
int 签到次数 = 0;

none 刷新() {
    settext(状态标签, "已签到 " + 签到次数 + " 次");
}

function on_click(int 控件) {
    if (控件 == 签到按钮) {
        签到次数 = 签到次数 + 1;
        settext(提示标签, "签到成功！");
    }
    else if (控件 == 撤销按钮) {
        if (签到次数 > 0) {
            签到次数 = 签到次数 - 1;
            settext(提示标签, "已撤销一次。");
        } else {
            settext(提示标签, "没有可撤销的记录了。");
        }
    }
    else if (控件 == 清零按钮) {
        签到次数 = 0;
        settext(提示标签, "已清零。");
    }
    刷新();
}

function main() {
    int 窗口 = window("签到计数器", 480, 320);
    提示标签 = label("点“签到”按钮开始", 24, 24, 430, 24);
    状态标签 = label("已签到 0 次", 24, 56, 430, 24);
    签到按钮 = button("签到", 24, 110, 120, 34);
    撤销按钮 = button("撤销", 160, 110, 120, 34);
    清零按钮 = button("清零", 296, 110, 120, 34);
    刷新();

}
```

### 拓展与规范

**控件号必须存在全局变量里。** 这是窗口程序最常见的错误：把 `签到按钮` 写成 `main` 里的局部变量，编译不报错，但 `on_click` 里比较的永远是 0，按钮点了没反应。

**事件函数的名字是固定的。** 只有 `on_click`、`on_change`、`on_close` 三个名字会被自动调用。写成 `onClick`、`点击` 都不会被调用，而且编译器不会提醒你。

**同一类事件只写一个函数。** 十个按钮也只有一个 `on_click`，靠 `if (控件 == ...)` 分派。别指望给每个按钮写一个函数。

**控件不要重叠。** 后添加的控件会盖住先添加的。坐标算错造成的"按钮点不到"，多半是这个问题。

**窗口程序不自动运行（本书的检查流程里）。** 因为 `run()` 会一直等用户关窗口，自动化检查里只做编译。你在本地按 F5 是能正常跑的。

**用 `alert` 代替 `print` 调试。** 没有控制台的时候，`print` 看不到；`alert("到这里了")` 会弹框，能确认程序走到哪一步。

**编译不过先看问题面板。** 窗口程序拼错函数名（比如 `lable`）会报"未知函数"，并提示相近的名字。

**窗口程序不需要 `return`。** `main` 结束时窗口已经关了，程序直接退出。

### 本章小结

- 第一行 `use "C_OPED.cash";` 打开窗口和 C 的世界，之后不用写任何 `include`。
- `window(标题, 宽, 高)` 开窗口，返回窗口号；一个程序只调用一次。
- 控件函数格式是 `(文字, x, y, 宽, 高)`，坐标以客户区左上角为原点，单位像素。
- 控件号存进**全局变量**，事件函数里才能区分是哪个控件。
- `on_click(int 控件)` 是按钮点击的入口，`settext(控件, 文字)` 改控件文字。
- `run()` 进入事件循环，窗口关闭后返回；窗口程序没有黑控制台，调试加 `--console`。

### 知识准备

#### 9.1 控件一览

| 控件函数 | 长什么样 | 典型用途 |
|---------|---------|---------|
| `label(文字, x, y, 宽, 高)` | 一行静态文字 | 提示、状态显示 |
| `button(文字, x, y, 宽, 高)` | 按钮 | 触发动作 |
| `textbox(文字, x, y, 宽, 高)` | 单行输入框 | 姓名、学号 |

| `progress(x, y, 宽, 高)` | 进度条（无文字参数） | 进度、完成度 |

#### 9.2 读写控件

| 函数 | 作用 | 说明 |
|------|------|------|
| `settext(控件, "文字")` | 改控件的文字 | 也能给输入框预填内容 |
| `string s = readtext(控件)` | 读控件的文字 | 返回 `string` |
| `settitle(控件, "文字")` | 改控件的标题 | 与 `settext` 类似 |
| `additem(列表, "一项")` | 往列表加一项 | 只对 `listbox` 有效 |
| `checked(勾选框)` | 读勾选状态 | 返回 1（勾）或 0（没勾） |
| `setchecked(勾选框, 1)` | 设置勾选状态 | 传 1 勾上，传 0 取消 |
| `setvalue(进度条, 50)` | 设置进度条的进度 | 0 到 100 |
| `getvalue(进度条)` | 读进度条的进度 | 返回整数 |

注意进度条读值用的是 **`getvalue`**。写 `value(...)` 会被拼写检查拦下来，因为 `VALUE` 是内置的"文字转数字"函数。

```cask
// 输入框互动
use "C_OPED.cash";

int 姓名框;
int 回显标签;

function on_change(int 控件) {
    settext(回显标签, "正在输入：" + readtext(姓名框));
}

function main() {
    int 窗口 = window("输入框演示", 480, 260);
    label("请输入姓名：", 24, 24, 200, 24);
    姓名框 = textbox("", 24, 56, 300, 28);
    回显标签 = label("正在输入：", 24, 110, 420, 24);
    int 按钮 = button("清空", 24, 150, 120, 34);
    run();
```

#### 9.5 事件函数：on_click、on_change、on_close

| 事件函数 | 什么时候被调用 | 参数 |
|---------|---------------|------|

### 拓展与规范

**`readtext` 拿到的是"当前文字"**，每次调用都会重新取一遍。想把输入框清空就 `settext(输入框, "")`。

**数字要从输入框取，得先转换。** `readtext` 返回的是字符串，要参与计算得用 `VALUE` 转成数字：

```cask
// 把输入框里的文字当数字用
use "C_OPED.cash";

function main() {
    int 窗口 = window("数字转换", 480, 240);
    int 输入 = textbox("123", 24, 24, 200, 28);
    int 结果 = label("结果：", 24, 80, 400, 24);
    print "提示：点按钮前请先在输入框里填一个整数";
    run();
}
```

真正计算时写成 `int n = VALUE(readtext(输入));` 注意 `VALUE` 会把小数部分截掉，要小数就先取文字再自己解析。

**进度条的范围是 0 到 100。** `setvalue(进度条, 150)` 不会报错，但显示会停在满格。要显示别刻度，自己换算一下。

**`sleep` 的单位是毫秒。** `sleep(1000)` 是一秒。界面在做 `sleep` 期间不会响应点击，别在按钮事件里写太长的 `sleep`。

**`on_close` 里不要写 `sleep` 或等待用户的长动作。** 它的用途是"记一笔、问一句"。

**事件函数里别写长循环。** 事件函数要尽快返回，界面才流畅。要处理很多数据，就在按钮事件里算完一次、刷新界面，别在 `on_change` 里做重活。

**`settext` 和 `settitle` 都可以改控件文字。** 表格里的单元格用 `settext` 更直观，代码风格统一即可。

**中文显示不用管编码。** `C_OPED.cash` 内部按 UTF-8 处理，程序里的中文会正确显示在窗口上；源文件仍然要保存为 UTF-8。

### 知识准备

#### 10.1 两种 use：尖括号和引号

`use` 有两条路：

```cask
use <stdio.h>;        // 尖括号：系统头文件 → 生成 #include <stdio.h>
use <math.h>;
```

```cask
use "my_helper.h";    // 引号带 .h：自己的头文件 → 生成 #include "my_helper.h"
```

- 尖括号里的名字，编译器去**系统目录**找，像 `stdio.h`、`math.h`、`string.h`。
- 引号里的名字，先从**程序所在目录**找，找不到再找系统目录，通常放你自己写的 `.h`。

`use` 只能写在文件最上面，要在函数定义之前。

#### 10.2 第三行 use "C_OPED.cash";：打开直通调用

`use "C_OPED.cash";` 是个例外：它不是让你自己去翻头文件，而是一次把系统头文件全包含进来、把窗口库全链接上。之后：

| 效果 | 说明 |
|------|------|
| 头文件已经包含 | 不用再写 `use <windows.h>;` |
| 函数不用声明就能调 | 直接写 `GetTickCount()`、`MessageBoxA(...)` |
| 常量也能直接用 | 像 `MB_OK`、`MB_OKCANCEL` 这类 Win32 常量 |
| 自动链接窗口库 | user32、gdi32、comctl32 等不用自己写 |

代价是：程序变成**窗口式程序**，运行时不再有黑色控制台窗口，`print` 的输出也就没地方显示（调试时加 `--console`，见"拓展与规范"）。

#### 10.3 计时：GetTickCount

`GetTickCount()` 返回"开机到现在的毫秒数"，是个整数。用它夹住一段代码，两头相减就是耗时：

```cask
int 开始 = GetTickCount();
// ……要计时的代码……
int 用时 = GetTickCount() - 开始;
```

`用时` 的单位是毫秒。系统计时器的精度大约是 10 到 16 毫秒，所以很短的计算量出来常常是 0。

#### 10.4 原生消息框：MessageBoxA

```cask
MessageBoxA(0, "正文", "标题", MB_OK);
```

四个参数：窗口句柄（没有就写 0）、正文、标题、按钮和图标选项。`MB_OK` 表示"只有一个确定按钮"，这些常量来自 `C_OPED.cash` 打开的系统头文件。

弹出框以后程序会停在那里，等用户点按钮，再继续往下走。

#### 10.5 调 C 标准库函数：puts 和 strlen

`C_OPED.cash` 打开以后，标准库函数也能直接调：

```cask
use "C_OPED.cash";

function main() {
    string s = "C* 语言";
    puts(s);
    print "字节数 ", strlen(s);
    print "字符数 ", LEN(s);
}
```

`puts` 打印一行文字，效果接近 `print`。`strlen` 数的是**字节数**，和 C* 的 `LEN` 结果一样（一个汉字 3 个字节）。

> `printf` 不要用：这个名字和 C* 自己的 `print` 太像，编译器会报 `不认识的函数 'printf'，是不是想写 'print'？`。要格式化输出就用 `print`，要打一行原始文字就用 `puts`。

#### 10.6 调用自己写的 C 函数：加头文件，写原型

想把自己写好的 C 函数搬进来，分两步。

第一步：把函数写进一个头文件，比如和程序放同一个目录的 `my_lib.h`：

```c
/* my_lib.h —— 自己写的工具函数 */
static long long double_it(long long x) { return x * 2; }
```

第二步：在 `.cask` 里"引入 + 声明"：

```cask
use "my_lib.h";

int double_it(int x);      // 原型：名字和参数要和 my_lib.h 一致
```

要点有三个：

- `use "my_lib.h";` 负责把内容包含进来。
- 那一行 `int double_it(int x);` 是**原型声明**，告诉编译器"这个函数存在、参数是什么类型"。
- C* 的 `int` 对应的 C 类型是 `long long`，所以头文件里的参数和返回值要写成 `long long`。

漏了原型，编译器会提示 `不认识的函数 'double_it'（如果它来自 'use' 的头文件，请先声明: ...）`。另外，自定义头文件要**和生成的可执行文件放在同一个目录**，否则编译时会报找不到这个头文件。

#### 10.7 类型对照：写错就报错

直通调用时，C* 把值按下面的规则翻译成 C 类型。自己写 C 函数时也要照着对：

| C* 类型 | C 类型 | 说明 |
|---------|--------|------|
| `int` | `long long` | 64 位整数 |
| `float` | `double` | 双精度小数 |
| `string` | `char *` | 字符串 |
| `char` | `char` | 单字符 |
| `bool` | `int` | 1 表示真，0 表示假 |
| `none` | `void` | 无返回值 |

#### 10.8 C# 用不了

```cask
use "C_OPED.cash";
```

```cask
int 成绩[8] = {88, 95, 72, 66, 91, 79, 84, 60};
int 人数 = 8;

int 结果标签;
int 统计按钮;

    return s;
```

```cask
function on_click(int 控件) {
    if (控件 != 统计按钮) return;
    int 开始 = GetTickCount();
    int 总 = 总分();
    int 用时 = GetTickCount() - 开始;
    string 报告 = "总分 " + 总 + " 分，最高 " + MAX(成绩) + " 分，最低 " + MIN(成绩) + " 分";
    settext(结果标签, 报告);

}

function main() {

    label("点按钮，统计这 8 个分数：", 24, 24, 460, 24);

}
```

### 拓展与规范

**窗口程序想保留控制台，编译时加 `--console`。** 加了这个参数，`print` 的输出就能在黑色窗口里看到，调试特别有用：

```bat
bin\caskc.exe report.cask --run --console
```

**直通调用不检查参数。** C* 只确认名字能对上系统里的某个符号；参数个数和类型由后面的 C 编译器把关。所以报错信息长得像 C 编译器的报错，但行号仍然指回你的 `.cask`：

```text
report.cask: In function '__cask_start':
report.cask:4:2: error: too few arguments to function 'MessageBoxA'
```

**标准库函数不要自己写原型。** 如果你在 `.cask` 里写 `int puts(string s);`，会和系统头文件里已有的声明冲突：

```text
error: conflicting types for 'puts'; have 'long long int(char *)'
```

`C_OPED.cash` 已经把标准头文件包含好了，标准库函数直接用；只有**自己写的** C 函数才需要写原型。

**报错时先把 `use` 那一行检查一遍。** 见到 `不认识的函数 'xxx'（如果它来自 'use' 的头文件，请先声明: ...）`，依次确认三件事：头文件加没加、原型写没写、名字拼对没有。

**借来的东西越多，程序越只认 Windows。** 用了 `MessageBoxA`、`GetTickCount` 这类系统函数，程序就绑死在 Windows 上了。写通用的练习时，能用 C* 自带函数就用自带的。

**参数顺序要查文档。** Win32 函数有一千多个，C* 不替你背。用哪个、参数什么顺序、常量怎么拼，去查函数说明或 MSDN，抄准了再用。

### 本章小结

- `use <名字>;` 引系统头文件，`use "名字.h";` 引自己的头文件，都写在文件最上面。
- `use "C_OPED.cash";` 一次打开 C / C++ / Win32：头文件全包含、库全链接、函数不用声明就能调。
- `GetTickCount()` 取毫秒计数，两头相减就是耗时；计时器精度约十几毫秒。
- `MessageBoxA(0, 正文, 标题, MB_OK)` 弹原生消息框，`MB_OK` 是系统常量。
- `puts`、`strlen` 这些标准库函数可以直接调；`printf` 因为和 `print` 撞名不能用。
- 调自己写的 C 函数要两步：`use "xxx.h";` 加一行 `int 函数名(...);` 原型。
- 直通调用 C* 不查参数，类型错误由 C 编译器报，行号仍指回源文件。
- C# / .NET 用不了。

| 编号 | 功能 | 输入 | 输出 |
|------|------|------|------|
| F1 | 登记 | 应到人数、学号 | 名单追加一行，人数加一 |

要分析的三件事：**界面有哪些控件**、**数据存在哪里**、**每件事由谁做**。

### 知识准备

#### 11.1 开发流程：六步走

一个能交付的小项目，不是"坐下来就敲代码"，而是六步：

| 步骤 | 做什么 | 本项目的产物 |
|------|--------|--------------|
| 1 需求分析 | 把口头需求变成功能表 | 上面那张 F1 到 F4 的功能表 |
| 2 界面设计 | 画控件表，定好坐标 | 11.2 的控件表 |
| 3 数据结构与函数划分 | 定全局变量和函数职责 | 11.3 的表 |
| 4 编码 | 按划分把函数一个个写出来 | `attend.cask` |
| 5 测试 | 按用例表逐条验证 | 11.5 的测试表 |
| 6 交付 | 整理文件、写说明 | 11.6 的交付清单 |

前四步里，**最容易被跳过、也最容易翻车的是第 2、3 步**。界面位置没想清楚，控件会挤成一团；函数职责没分清，`on_click` 会写成一锅粥。

#### 11.2 界面设计：先画控件表

窗口按 620×480 设计，控件都按"文字, x, y, 宽, 高"来放：

| 控件 | 类型 | 位置与大小 | 用途 |
|------|------|-----------|------|
| 学号框 | `textbox` | 90, 20, 180, 28 | 输入学号 |
| 应到框 | `textbox` | 400, 20, 80, 28 | 输入应到人数，默认 60 |
| 登记按钮 | `button` | 500, 20, 90, 30 | 触发 F1 |
| 名单框 | `memo` | 24, 64, 300, 300 | 显示已到名单 |
| 进度条 | `progress` | 340, 64, 250, 24 | 显示到课率 |
| 状态标签 | `label` | 340, 100, 260, 72 | 显示人数和到课率 |
| 结束按钮 | `button` | 340, 190, 130, 34 | 触发 F3 |

两点说明：

- 名单用 `memo` 而不是 `listbox`，因为**要能整体清空**。`memo` 直接 `settext(名单框, "")` 就空了，`listbox` 没有"清空"这个函数。
- 每个要读要写的控件，都要用全局变量把控件号存住。

#### 11.3 数据结构与函数划分

数据只有三个整数：

| 变量 | 含义 |
|------|------|
| `应到` | 应到人数 |
| `已到` | 已登记人数 |
| `开始时刻` | 程序启动时的 `GetTickCount()` |

函数按职责分：

| 函数 | 职责 | 谁调用它 |
|------|------|----------|
| `到课率()` | 算并返回 0 到 100 的整数百分比 | `刷新()`、状态显示 |
| `刷新()` | 更新状态标签和进度条 | 登记后、启动时 |
| `登记(学号)` | 校验并录入一个人 | `on_click()` |
| `on_click(控件)` | 分发按钮点击 | 系统自动调用 |
| `on_close()` | 关窗口时提醒 | 系统自动调用 |
| `main()` | 建窗口、建控件、进事件循环 | 程序入口 |

**关键原则：事件函数只做分发，真正的活交给普通函数。** `on_click` 里只写 `if (控件 == 登记按钮) { ... }`，具体的校验和录入放到 `登记()` 里，这样界面部分和业务部分分得开，改哪块都不牵连另一块。界面统一的更新只走 `刷新()` 一个出口。

#### 11.4 一次全局变量的读写顺序

窗口程序里，全局变量在函数之前声明；`main` 里要先建控件，再读控件的初始值：

```cask
应到 = VALUE(readtext(应到框));
if (应到 <= 0) { 应到 = 60; }
开始时刻 = GetTickCount();
刷新();
run();
```

读 `readtext(应到框)` 得到的是文字，用 `VALUE` 转成整数。用户误删了默认值，就回落到 60。

**第 2 步　写全局变量和三个普通函数。** 先声明全部全局变量，再写 `到课率()`、`刷新()`、`登记()`：

```cask
use "C_OPED.cash";

int 应到 = 0;
int 已到 = 0;
int 开始时刻 = 0;

int 学号框;
int 应到框;
int 登记按钮;
int 结束按钮;
int 名单框;
int 进度条;
int 状态标签;

    if (应到 <= 0) { return 0; }
    int 率 = 已到 * 100 / 应到;
    if (率 > 100) { return 100; }
    return 率;
}

function 刷新() {
    settext(状态标签, "已到 " + 已到 + " 人 / 应到 " + 应到 + " 人\n到课率 " + 到课率() + "%");
    setvalue(进度条, 到课率());
}

function 登记(string 学号) {
    if (LEN(TRIM(学号)) == 0) {
        alert("学号不能为空。");
        return;
    }
    if (已到 >= 应到) {
        alert("应到人数已满，不能再登记。");
        return;
    }
    已到 = 已到 + 1;
    settext(名单框, readtext(名单框) + 已到 + ". " + TRIM(学号) + "\n");
    settext(学号框, "");
    刷新();
}
```

注意 `到课率()` 和 `MAX` 的差别：这里不能用 `MAX`——到课率要限在 100 以内，超过了也得压回 100，所以自己写一个函数最清楚。

**第 3 步　写事件函数。** `on_click` 只做分发；`on_close` 只做一次提醒：

```cask

function on_close() {

    }
}
```

### 拓展与规范

这一节是本章的重点：**项目怎么交付**。

**目录怎么摆。** 一个项目一个文件夹，里面分三块：源码、可执行、文档。

```text
机房考勤登记\
    src\    attend.cask              （源码）
    bin\    attend.exe  C_OPED.cash  （可执行文件和它依赖的库）
    docs\   需求与设计说明.md
            测试记录.md
            用户手册.md
```

源码和可执行分开，别人拿到手一眼就知道哪个是给人看的、哪个是给机器跑的。

**命名要有规律。**

| 类别 | 规范 | 例子 |
|------|------|------|
| 变量 | 名词，看名字知道存什么 | `应到`、`已到`、`学号框` |
| 函数 | 动词或动宾短语，看名字知道做什么 | `刷新()`、`登记()`、`到课率()` |
| 控件变量 | 名词加"框""按钮""标签" | `学号框`、`登记按钮`、`状态标签` |
| 常量 | 全大写，或用整词 | `MAX_NUM`、`最多人数` |

同一个词不要一会儿叫"学号"、一会儿叫"编号"。名字起对了，代码不用注释也能读懂一半。

**注释写"为什么"，不写"是什么"。** 下面这种注释是废话：

```cask
已到 = 已到 + 1;        // 已到加一
```

有价值的注释在最上面和关键判断处：

```cask
// 到课率限在 100 以内：应到填小了也不让进度条溢出
if (率 > 100) { return 100; }
```

每个文件开头写一段头注释：项目名、功能、作者、日期、运行环境。每个函数上面写一句这个函数干什么、参数什么意思。

**格式统一。** 缩进统一用 4 个空格（编辑器里按 Tab 会自己转换）；一行只写一句；`if`、`while`、`for` 后面即使只有一句也加 `{ }`，将来加代码不用回头找。

**文档要写三份。**

| 文档 | 给谁看 | 写什么 |
|------|--------|--------|
| 需求与设计说明 | 老师、评审 | 功能表、控件表、函数划分 |
| 测试记录 | 自己、评审 | 测试用例表，每条的实际结果和是否通过 |
| 用户手册 | 使用软件的人 | 怎么启动、每个按钮干什么、常见问题 |

用户手册最好写成"三步走"：双击哪个文件打开、第一步填什么、第二步点什么。不要说"调用 `登记()` 函数"，使用者看不懂。

**交付清单。** 交作业或交给用户时，按清单点一遍：

| 序号 | 交付物 | 检查点 |
|------|--------|--------|
| 1 | 源码 `.cask` | 能重新编译通过，没有警告 |
| 2 | 可执行文件 | 在一台没装过环境的电脑上能双击运行 |
| 3 | 依赖文件 | 窗口程序要带上 `C_OPED.cash` |
| 4 | 需求与设计说明 | 功能表、控件表齐全 |
| 5 | 测试记录 | 用例表有实际结果 |
| 6 | 用户手册 | 三步之内能看懂怎么用 |

**可执行文件要能独立运行。** 窗口程序依赖 `C_OPED.cash`，交货时它必须和 `.exe` 在同一个目录，这也是清单第 3 条专门盯着它的原因。

**答辩讲四个问题就够。** 功能是什么、数据怎么存、难点在哪里怎么解决的、测试怎么做的。讲"我调用了 `GetTickCount` 算到课率"比讲"我用了一个函数"有分量得多。

### 本章小结

- 一个可交付的项目走六步：需求分析、界面设计、数据结构与函数划分、编码、测试、交付。
- 界面先画控件表（类型、坐标、用途），再照着表建控件。
- 数据用全局变量，函数按职责分：事件函数只分发，业务放在普通函数里。
- 界面更新统一走一个 `刷新()`，避免多处写法不一致。
- 测试用例要覆盖正常、边界、异常三类，并留下实际结果。
- 命名、注释、缩进、文件组织是四项基本规范；注释写"为什么"。
- 交付要齐六样：源码、可执行、依赖文件、设计说明、测试记录、用户手册。

## 附录 B　错误分级与调试流程

### B.1 四类问题

编辑器把问题分成四级，状态栏上用四块小牌子显示各自的数量：

| 级别 | 代号 | 含义 | 程序能不能跑 |
|------|------|------|--------------|
| 严重 | `E` | 类型不对、名字冲突这类硬错误 | 跑不起来 |
| 语法 | `S` | 写法不对，比如少分号、括号不配对 | 跑不起来 |
| 拼写 | `P` | 名字打错了，编译器会猜一个正确的 | 跑不起来 |
| 提示 | `H` | 只是建议，比如用了老名字 | 能跑 |

用 `--check --diag` 时，每条问题按 `级别|行|列|信息` 的形式打出来。

### B.2 严重错误（E）

```text
E|2|18|不能把 string 放进 int
```

把字符串塞进了整数。改法：确认两边类型一致，用 `VALUE` 转换，或者把这个变量改成 `string`。

```text
E|3|15|参数 1（LEN()）应该是 string，但实际是 int
```

`LEN()` 要的是字符串，给的是整数。改法：传字符串，或者换成适合数字的函数。

```text
E|3|19|'i' 在这里已经声明过了
```

同一层里 `i` 声明了两次，常见于两个 `for (int i = ...)`。三种改法：先声明 `int i;` 两处都用 `for (i = ...)`；起两个不同的名字；或者给其中一个循环套一层 `{ }`。

### B.3 语法错误（S）

```text
S|3|34|这里要写 ';'，它要写在 print 后面，但是碰到了 '；'
```

分号写成了全角 `；`。改法：切到英文输入法，用半角 `;`。中文标点在代码里一律不能用。

```text
S|2|5|这里要写 ';'，它给这条声明收尾，但是碰到了 'print'
```

上一行少写了分号，编译器读到下一行的 `print` 才发现。改法：给上一行补分号。**报错的行不一定是真正出错的行**，凡是提示 `这里要写 ';'` 却看不出问题的，往上一行找。

### B.4 拼写错误（P）

```text
P|3|11|不认识的名称 '成积'，是不是想写 '成绩'？
```

名字打错了，编译器猜出了你想写的名字。改法：照提示改。

```text
P|4|5|不认识的函数 'printf'，是不是想写 'print'？
```

函数名不对，或者忘了引入头文件。用到自己写的 C 函数时，还要补一行原型声明。

### B.5 提示（H）

```text
H|2|5|'number' 是旧写法，现在写 'int'
```

用了老类型名。能编译也能运行，但新代码请写新名字。

### B.6 运行时错误

编译通过、运行出问题时，程序立刻停下并打印一行：

```text
C* 运行错误: 除以零
  位置 e_div.cask:4
```

| 信息 | 触发条件 | 常见原因 |
|------|----------|----------|
| `除以零` | `/` 或 `%` 的除数为 0 | 除数在循环里被算成了 0 |
| `数组下标越界` | 下标小于 0，或者不小于长度 | 循环写成 `<=`，或下标算大了 |
| `整数乘法溢出` | 乘法的结果装不下 | 参与运算的数太大 |
| `移位位数必须是 0..63` | 移位位数超出范围 | 移位位数写错 |
| `MID() 的位置从 1 开始（和 Excel 一样）` | `MID` 的位置写成 0 | 位置从 1 开始 |

这些检查可以用 `--fast` 关掉，但只有在确认逻辑正确、追求速度时才关。

### B.7 调试流程

1. 先看状态栏的四块牌子。有严重或语法问题，程序根本编译不过，先修这些；提示级可以最后再说。
2. 从**第一条**错误开始修。后面的错误常常是第一条引起的，改完一条重新看一遍。
3. 双击问题面板里的一条，跳到出错行，重点看这一行和**上一行**。
4. 编译通过却结果不对，先量数据：在关键位置加 `print`，把中间变量打出来对。
5. 运行时错误照报错的行号查：除零看除数，越界看下标表达式。
6. 一次只改一处，改完立刻重跑。同时改好几处，出了问题分不清是谁造成的。

### B.8 高频错误对照表

| 现象 | 多半是 |
|------|--------|
| `这里要写 ';'` | 上一行少分号，或者用了全角标点 |
| `不能把 string 放进 int` | 类型不匹配，需要 `VALUE` 转换 |
| `不认识的名称 'xx'` | 变量名打错，或全局变量声明在函数之后 |
| `不认识的函数 'xx'` | 函数名打错，或漏了头文件 / 原型 |
| `'i' 在这里已经声明过了` | 同一层写了两个 `for (int i = ...)` |
| 窗口一闪就没 | 忘了写 `run()` |
| 按钮点了没反应 | `on_click` 名字写错，或控件号没存对 |
| 中文显示成方块 | 源文件没存成 UTF-8，用菜单「编辑 → 转成 UTF-8」 |
| `找不到 'C_OPED.cash'` | 它和 `caskc.exe` 不在同一个目录 |

## 附录 C　从 C* 到 C 的对照表

C* 先翻译成 C，再由 gcc 编译成 exe。看懂生成的 C，能帮你理解为什么有些规则是那样。

### C.1 类型对照

| C* | C | 说明 |
|----|---|------|
| `int` | `long long` | 整数常量后面带 `LL` |
| `float` | `double` | 小数一律双精度 |
| `string` | `char *` | 字符串 |
| `char` | `char` | 单字符 |
| `bool` | `int` | 真为 1，假为 0 |
| `none` | `void` | 无返回值 |

### C.2 语法对照

```text
C*                              C
function main() { }             int main(void) { ... return 0; }
constant int N = 5;             #define N (5LL)
int a = 3;                      long long a = (3LL);
float x = 0.5;                  double x = (0.5);
string s = "hi";                char * s = ("hi");
bool b = true;                  int b = (1);
print a, b;                     cask_p_num(a); cask_p_str(b); cask_nl();
a * b                           cask_mul(a, b, __FILE__, 行号)
a + b                           cask_add(a, b, __FILE__, 行号)
a / b                           cask_div(a, b, __FILE__, 行号)
input x;                        按行读入并按类型解析
and  or  not                    &&   ||   !
IF(c, a, b)                     (c) ? (a) : (b)
MOD(a, b)                       结果的符号跟除数（C 的 % 跟被除数）
越界 / 溢出 / 除零              运行时检查并报错（C 里是未定义行为）
use "C_OPED.cash";              包含 windows.h + 链接窗口库 + 生成 WinMain
```

### C.3 同一段程序的两种写法

C* 原文：

```cask
int 单价 = 3;

function main() {
    int 数量 = 4;
    print "总价 ", 单价 * 数量;
}
```

生成的 C（节选）：

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "cask_rt.h"

#line 1 "c3.cask"
long long 单价 = (3LL);

#line 3 "c3.cask"
static int __cask_start(void)
{

#line 4 "c3.cask"
	long long 数量 = 4LL;

#line 5 "c3.cask"
	cask_p_str("总价 ");
	cask_p_num(cask_mul(单价, 数量, __FILE__, 5));
	cask_nl();
	return 0;
}
int main(void)
{
	cask_init(65001);
	return __cask_start();
}
```

要看的几点：

- `int` 变成了 `long long`，常量带上了 `LL`。
- `print` 拆成了 `cask_p_str`、`cask_p_num`，最后加一个 `cask_nl()` 换行。
- 乘法变成了 `cask_mul(单价, 数量, __FILE__, 5)`，多传了文件名和行号——越界、溢出、除零的报错就是从这里拿到位置的。
- `#line` 让 C 编译器报错时指向 `.cask` 源文件，而不是生成的 `.c`。

### C.4 编译命令

只看生成的 C：

```text
bin\caskc.exe 程序.cask --emit-c out.c
```

编译器背后调用的 gcc 大致是：

```text
gcc -O2 -s -o out.exe out.exe.gen.c -I "…\bin" -lm
```

窗口程序会加上 `-mwindows` 和一组窗口库：

```text
-mwindows -luser32 -lgdi32 -lcomctl32 -lole32 -luuid -lshell32 -lcomdlg32 -lmsimg32
```

### C.5 从 C* 转到 C 要注意

- C* 的越界、溢出、除零检查，到了 C 里全都没有；C 出这类问题是未定义行为，可能不报错、可能乱跑。
- 字符串在 C 里就是 `char *`，长度要自己算，内存要自己管。
- `bool` 在 C 里是 `int`，打印要用 `cask_p_bool`，不能当普通整数随便打。
- C 的 `printf` 格式必须自己配对（`%lld` 对 `long long`），配错了不报错，直接输出乱码。

## 附录 D　综合项目

这里给出两个完整的项目源码，一个控制台程序、一个窗口程序。两者都可以直接编译运行，可以当成自己项目的模板。

### D.1 项目一：简易库存管理（控制台）

**需求。** 一个小库房，最多 50 种货物，每样记品名、单价、库存数量。需要一个控制台程序，能入库、出库、按品名查询、列出全部、统计库存总价值。

**功能表。**

| 编号 | 功能 | 输入 | 输出 |
|------|------|------|------|
| 1 | 入库 | 品名、数量、单价 | 新增品种或累加库存 |
| 2 | 出库 | 品名、数量 | 扣减库存或提示不足 |
| 3 | 查询 | 品名 | 该品种的单价和库存 |
| 4 | 列出 | 无 | 全部品种各一行 |
| 5 | 统计 | 无 | 品种数、总数量、总价值、库存最多的品种 |
| 0 | 退出 | 无 | 结束 |

**数据结构。** 三个平行数组加一个计数：`品名[50]` 存名字，`单价[50]` 存单价，`库存[50]` 存数量，`种类` 记住现在有多少种（同时就是下一个空位的下标）。

**函数划分。**

| 函数 | 职责 |
|------|------|
| `找位置(名)` | 返回该品名的下标，没有就返回 -1 |
| `入库()` | 新增品种或给已有品种加量 |
| `出库()` | 校验数量后扣减 |
| `查询()` | 打印一个品种的信息 |
| `列出()` | 逐行打印全部品种 |
| `统计()` | 汇总数量、价值，找出库存最多的品种 |
| `main()` | 菜单循环，按选择调用上面几个函数 |

**完整源码 `inventory.cask`：**

```cask
// inventory.cask —— 简易库存管理（控制台）
constant int 最多 = 50;

string 品名[50];
int 单价[50];
int 库存[50];
int 种类 = 0;

int 找位置(string 名) {
    int i;
    for (i = 0; i < 种类; i++) {
        if (品名[i] == 名) { return i; }
    }
    return -1;
}

function 入库() {
    if (种类 >= 最多) {
        print "库位已满，不能再加新品种。";
        return;
    }
    string 名;
    show "品名：";
    input 名;
    int 量;
    int p = 找位置(名);
    if (p >= 0) {
        show "已有该品种，本次入库数量：";
        input 量;
        库存[p] += 量;
        print 名, " 入库 ", 量, "，现有 ", 库存[p];
    } else {
        show "入库数量：";
        input 量;
        show "单价：";
        input 单价[种类];
        品名[种类] = 名;
        库存[种类] = 量;
        种类++;
        print "新增品种 ", 名, "，库存 ", 量;
    }
}

function 出库() {
    string 名;
    show "出库品名：";
    input 名;
    int p = 找位置(名);
    if (p < 0) {
        print "没有这种品名：", 名;
        return;
    }
    int 量;
    show "出库数量：";
    input 量;
    if (量 > 库存[p]) {
        print "库存不足，目前只有 ", 库存[p];
        return;
    }
    库存[p] -= 量;
    print 名, " 出库 ", 量, "，剩余 ", 库存[p];
}

function 查询() {
    string 名;
    show "查询品名：";
    input 名;
    int p = 找位置(名);
    if (p < 0) {
        print "没有这种品名：", 名;
        return;
    }
    print 品名[p], " 单价 ", 单价[p], " 元，库存 ", 库存[p];
}

function 列出() {
    if (种类 == 0) {
        print "库房是空的。";
        return;
    }
    int i;
    for (i = 0; i < 种类; i++) {
        print 品名[i], " 单价 ", 单价[i], " 元，库存 ", 库存[i];
    }
}

function 统计() {
    if (种类 == 0) {
        print "库房是空的。";
        return;
    }
    int 总数量 = 0;
    int 总价值 = 0;
    int 最多库存 = 库存[0];
    int 最多位置 = 0;
    int i;
    for (i = 0; i < 种类; i++) {
        总数量 += 库存[i];
        总价值 += 库存[i] * 单价[i];
        if (库存[i] > 最多库存) {
            最多库存 = 库存[i];
            最多位置 = i;
        }
    }
    print "品种 ", 种类, "，总数量 ", 总数量, "，总价值 ", 总价值, " 元";
    print "库存最多的是 ", 品名[最多位置], "（", 最多库存, " 件）";
}

function main() {
    print "==== 简易库存管理 ====";
    int 选择 = -1;
    while (选择 != 0) {
        print "1 入库  2 出库  3 查询  4 列出  5 统计  0 退出";
        show "请选择：";
        input 选择;
        if (选择 == 1) { 入库(); }
        else if (选择 == 2) { 出库(); }
        else if (选择 == 3) { 查询(); }
        else if (选择 == 4) { 列出(); }
        else if (选择 == 5) { 统计(); }
        else if (选择 == 0) { print "再见。"; }
        else { print "没有这个选项，请重选。"; }
    }
}
```


**验收要点。**

- 同一个品名再入库，是"加量"而不是新增一行。

- 输入 9 这类不存在的选项，给出提示后回到菜单。

### D.2 项目二：学生成绩录入与统计（窗口）

**需求。** 教师用窗口程序逐个录入学生姓名和分数，左边实时显示名单，右边显示已录人数和平均分；点"统计"弹出一个汇总框；点"清空"要先确认。

**控件表。**

| 控件 | 类型 | 位置与大小 | 用途 |
|------|------|-----------|------|
| 姓名框 | `textbox` | 90, 20, 150, 28 | 输入姓名 |
| 分数框 | `textbox` | 320, 20, 80, 28 | 输入分数 |
| 添加按钮 | `button` | 420, 20, 90, 30 | 录入一条 |
| 名单框 | `memo` | 24, 64, 360, 320 | 显示全部记录 |
| 状态标签 | `label` | 400, 64, 220, 60 | 显示人数和平均分 |
| 统计按钮 | `button` | 400, 136, 100, 34 | 弹出汇总框 |
| 清空按钮 | `button` | 510, 136, 100, 34 | 确认后清空 |

**完整源码 `grades.cask`：**

```cask
// grades.cask —— 学生成绩录入与统计（窗口）
use "C_OPED.cash";

int 人数 = 0;
int 总分 = 0;
int 最高分 = 0;
int 最低分 = 0;
int 开始时刻 = 0;

int 姓名框;
int 分数框;
int 添加按钮;
int 统计按钮;
int 清空按钮;
int 名单框;
int 状态标签;

function 刷新() {
    if (人数 == 0) {
        settext(状态标签, "还没有录入成绩。");
        return;
    }
    settext(状态标签, "已录 " + 人数 + " 人\n平均 " + ROUND(总分 * 1.0 / 人数, 1) + " 分");
}

function 添加() {
    string 姓名 = TRIM(readtext(姓名框));
    int 分数 = VALUE(readtext(分数框));
    if (LEN(姓名) == 0) {
        alert("姓名不能为空。");
        return;
    }
    if (分数 < 0 or 分数 > 100) {
        alert("分数要在 0 到 100 之间。");
        return;
    }
    人数 = 人数 + 1;
    总分 = 总分 + 分数;
    if (人数 == 1) {
        最高分 = 分数;
        最低分 = 分数;
    }
    if (分数 > 最高分) { 最高分 = 分数; }
    if (分数 < 最低分) { 最低分 = 分数; }
    settext(名单框, readtext(名单框) + 人数 + ". " + 姓名 + "  " + 分数 + " 分\n");
    settext(姓名框, "");
    settext(分数框, "");
    刷新();
}

function on_click(int 控件) {
    if (控件 == 添加按钮) {
        添加();
        return;
    }
    if (控件 == 统计按钮) {
        if (人数 == 0) {
            alert("还没有录入成绩。");
            return;
        }
        int 用时 = GetTickCount() - 开始时刻;
        string 报告 = "共 " + 人数 + " 人\n总分 " + 总分 + "\n平均 " + ROUND(总分 * 1.0 / 人数, 1) + "\n最高 " + 最高分 + "\n最低 " + 最低分;
        MessageBoxA(0, 报告, "成绩统计（运行 " + 用时 + " 毫秒）", MB_OK);
        return;
    }
    if (控件 == 清空按钮) {
        if (人数 == 0) { return; }
        if (ask("确定清空所有成绩吗？", "确认") == 1) {
            人数 = 0;
            总分 = 0;
            最高分 = 0;
            最低分 = 0;
            settext(名单框, "");
            刷新();
        }
    }
}

function main() {
    window("成绩录入与统计", 640, 460);
    label("姓名：", 24, 24, 60, 24);
    姓名框 = textbox("", 90, 20, 150, 28);
    label("分数：", 260, 24, 60, 24);
    分数框 = textbox("", 320, 20, 80, 28);
    添加按钮 = button("添加", 420, 20, 90, 30);

    名单框 = memo("", 24, 64, 360, 320);
    状态标签 = label("", 400, 64, 220, 60);
    统计按钮 = button("统计", 400, 136, 100, 34);
    清空按钮 = button("清空", 510, 136, 100, 34);

    开始时刻 = GetTickCount();
    刷新();
    run();
}
```

**运行时你会看到什么。**

- 一个 640×460 的窗口，标题"成绩录入与统计"，上面两行输入框和"添加"按钮。
- 输姓名和分数，点"添加"：左边名单多出一行"1. 张三  88 分"，右边状态变成"已录 1 人\n平均 88 分"。两个输入框自动清空。
- 分数填成 120 或 -5，提示"分数要在 0 到 100 之间。"；姓名不填，提示"姓名不能为空。"。
- 点"统计"：弹出"共 N 人 / 总分 / 平均 / 最高 / 最低"，标题里带运行毫秒数。
- 点"清空"：先弹"确定清空所有成绩吗？"，选"是"则名单和统计一起归零，选"否"什么都不变。
- 一个人都没录就点"统计"或"清空"，不弹汇总框、不清空。

**测试用例表。**

| 编号 | 测试内容 | 操作 | 期望结果 |
|------|----------|------|----------|

## 附录 F　彩蛋与暗号：`rcl()`

> 附录 A 到 E 是查资料用的，这一篇不一样：它是给你"玩"的。C* 里藏了一个内置函数 `rcl`，
> 它不解决业务问题，但很适合做口令、暗号、急停开关，也是你读别人代码时的一个小惊喜。
> 篇幅不长，读完你应该能自己给项目藏一个。

### F.1 学习目标

- 说清 `rcl()` 和 `rcl(值)` 各做什么，什么情况下它什么也不做。
- 会用 `rcl()` 写"立刻结束程序"的急停开关，并说清它和 `return` 的区别。
- 会把暗号藏进一个窗口程序，而且不影响窗口的正常功能。
- 知道彩蛋代码应该写在哪里，交付时要交代什么。

### F.2 任务引入

机房里几个同学一起写一个"库存小工具"，约定了一个只有组内人才知道的口令：

- 输入 `235`，或者 `FC235`、`JF235` 这类暗号，程序回一句自己人看得懂的话；
- 输入别的，程序装作什么也没发生，照常干活；
- 演示的时候还想留一个"急停"：敲一下空口令，程序立刻结束，别让人在讲台上乱点。

`rcl` 就是 C* 为这种需求准备的内置函数。它不用 `use`，也不用自己写函数体，直接调用就行。

### F.3 知识准备：`rcl` 的三条规矩

| 写法 | 结果 |
|------|------|
| `rcl();` | 输出一行 `方程235永远爱rcl！`，然后**立刻结束整个程序**，它后面的语句一句都不执行 |
| `rcl(235);` | 输出一行 `方程235 爱 rcl` |
| `rcl("FC235");` | 输出一行 `方程235 爱 rcl` |
| `rcl("rcl");` | 输出一行 `rcl，方程235永远爱你！` |
| 别的值，例如 `rcl(1);`、`rcl("hello");` | **什么也不做**，程序继续往下跑 |

一句话记住：空着调用是"说完就走"，对上暗号是"回一句"，别的值就是"没听见"。

**只有一个参数时，它认得下面这些值**

| 参数类型 | 认得的写法 |
|----------|-----------|
| 数字 | `235`（写成 `235.0` 的小数也认） |
| 字符串 | `235`、`方程235`、`FangCheng235`、`ZFC235`、`JF235`、`JF`、`FC235`、`FC`、`ZFC`、`FangCheng`，**不分大小写**（`fc235`、`jf` 也认） |

另外三条附带说明，写错的时候用得上：

- `rcl` 的返回值是整数（`int`）0，所以 `int 结果 = rcl(235);` 是合法写法，只是没人关心这个 0。
- 给两个参数会报错：`rcl() 要么不写参数、要么写一个值，这里是 2 个`。
- 参数是数组会报错：`rcl() 要 int 或 string`。

### F.4 任务实施一：口令验证器

第一个任务：让程序先问一句口令，对上暗号就回话，对不上就继续干活。

```cask
// 口令验证器：对上暗号才回一句话
function main() {
    string 口令;
    print "请输入口令：";
    input 口令;
    rcl(口令);                    // 字符串暗号：235 / FangCheng235 / ZFC235 / JF235 / JF / FC235 / FC
    print "程序继续运行。";
}
```

先输入 `FC235`：

```text
请输入口令：
FC235
方程235 爱 rcl
程序继续运行。
```

再输入 `12345`：

```text
请输入口令：
12345
程序继续运行。
```

注意两件事。第一，`rcl` **不会**结束程序，它只是回一句话，所以后面的 `print` 照样执行。第二，要让口令既认数字也认文字，先把输入转成整数再比对，用第 3 章学过的 `VALUE`：

```cask
int 密码;
print "请输入数字暗号：";
input 密码;
rcl(密码);                        // 输入 235 就回一句
rcl("ZFC235");                    // 字符串暗号可以直接写在程序里
print "暗号检查完毕。";
```

### F.5 任务实施二：急停开关

空参数的 `rcl();` 会结束**整个程序**，而且是从**任何位置**结束——哪怕它写在一个被调用的函数里。

```cask
// 急停开关：rcl() 从内层函数里直接结束整个程序
function 内层() {
    print "内层的结束语";
    rcl();                        // 空着调用：说一句话，然后整个程序到此为止
    print "这一句不会执行";
}

function main() {
    print "开始";
    内层();
    print "这一句也不会执行";
}
```

运行结果：

```text
开始
内层的结束语
方程235永远爱rcl！
```

把它和 `return` 比一比，区别就清楚了：

| 写法 | 结束谁 | 适合用在哪 |
|------|--------|-----------|
| `return;` / `return 0;` | 只结束**当前这个函数**，回到调用它的地方继续 | 正常的函数返回、参数不合法时提前退出 |
| `rcl();` | 结束**整个程序**，后面的代码全部不执行 | 急停开关、演示时的手动中止 |

下面这个例子把它用在输入循环里：敲 `-1` 立刻结束，敲别的照常处理。

```cask
// 急停开关：输入 -1 立刻结束，收尾代码不会执行
function main() {
    int 命令 = 0;
    while (true) {
        print "输入数字（-1 立刻退出）：";
        input 命令;
        if (命令 == -1) { rcl(); }
        print "收到：", 命令;
    }
    print "收尾：保存数据、关闭文件。";
}
```

运行结果是：

```text
输入数字（-1 立刻退出）：
7
收到：7
输入数字（-1 立刻退出）：
-1
方程235永远爱rcl！
```

最后那句 `收尾：保存数据、关闭文件。` **没有**打出来，这正是 `rcl()` 和正常退出的区别：它是"立刻断"，不走收尾。

### F.6 任务实施三：给考勤登记藏一个暗号

最后把它用进第 11 章那种窗口程序里。这次暗号是学号 `235`：填这个学号不走正常登记，而是打开"开发者模式"。

```cask
use "C_OPED.cash";

int 姓名框;
int 学号框;
int 名单框;
int 状态标签;
int 登记条数 = 0;

function 刷新状态() {
    settext(状态标签, "已登记 " + 登记条数 + " 条");
}

function 登记(string 姓名, string 学号) {
    settext(名单框, readtext(名单框) + 学号 + " " + 姓名 + "\r\n");
    登记条数 = 登记条数 + 1;
    刷新状态();
}

function on_click(int 控件) {
    string 姓名 = readtext(姓名框);
    string 学号 = readtext(学号框);
    if (LEN(学号) == 0) { settext(状态标签, "学号不能为空"); return; }
    if (VALUE(学号) == 235) {                 // 隐藏暗号：学号填 235
        rcl(235);                             // 说一句「方程235 爱 rcl」
        settext(状态标签, "开发者模式已打开");
        return;
    }
    登记(姓名, 学号);
}

function main() {
    window("机房考勤登记", 520, 430);
    label("姓名", 20, 24, 60, 24);
    姓名框 = textbox("", 80, 22, 150, 26);
    label("学号", 250, 24, 60, 24);
    学号框 = textbox("", 310, 22, 150, 26);
    button("登记", 20, 64, 120, 32);
    名单框 = memo("", 20, 110, 460, 230);
    状态标签 = label("已登记 0 条", 20, 350, 300, 24);
    run();
}
```

这里有两点和前面不同，交付时要跟同学讲清楚：

- 窗口程序**默认没有控制台**，`rcl` 打的那行字看不见。想看到它，编译运行时加 `--console`：`bin\caskc.exe 考勤.cask --run --console`。如果希望不依赖控制台，把暗号的反馈写在界面上（上面用 `settext(状态标签, …)` 就是这么做的）。
- 暗号判断要放在**正常流程之前**，判断成立后 `return`，这样彩蛋就不会污染正常登记逻辑。

### F.7 拓展与规范

彩蛋代码和业务代码混在一起，很容易变成"没人看得懂的怪代码"。下面几条是交付经验：

- **彩蛋要能被一眼认出来**：包成单独的函数（比如 `隐藏口令(口令)`），加一行注释说明它是彩蛋，别把 `rcl` 散落在业务逻辑里。
- **不要用 `rcl()` 当正常退出**：业务程序该保存的保存、该关的关，`rcl()` 会跳过全部收尾代码，只适合急停和演示。
- **别用它绕开循环**：从 `while (true)` 里退出应该用条件判断或 `break`，`rcl()` 是"把程序整个关掉"，不是"结束循环"。
- **交付说明里写一句**：如果有暗号，在 README 或演示文档里写一句"输入 235 有惊喜"，不然下一个维护的人只会以为程序写错了。
- **注意版本**：`rcl` 是 0.4.2 的内置函数。把程序交给别人之前，用 `bin\caskc.exe --version` 确认对方也是 0.4.2，否则会报"未知函数"。
- **别忘了测试**：暗号分支也要跑一遍，确认它对上暗号时只是多说一句话，不会破坏正常功能。

### F.8 本章小结

| 想做的事 | 写法 |
|----------|------|
| 立刻结束整个程序（并留一句话） | `rcl();` |
| 对上随机值暗号 | `rcl(235);` |
| 对上字符串暗号 | `rcl("FC235");` 或 `rcl(口令);` |
| 什么也不做 | `rcl(别的值);` |
| 让用户输入的文字能按数字比对 | `VALUE(文字)` |

`rcl` 不改变程序的业务逻辑，它只是给程序留了一个只有自己人才知道的入口。用得好是彩蛋，用不好是坑。

### F.10 本章测验

1. 判断题：`rcl(235);` 会结束整个程序。
2. 判断题：`rcl();` 后面的语句还会执行。
3. 选择题：下面哪个写法会输出 `方程235 爱 rcl`。A. `rcl();` B. `rcl(1);` C. `rcl("JF");` D. `rcl("hello");`
4. 选择题：想让程序在任何位置立刻结束，应该用。A. `return;` B. `break;` C. `rcl();` D. `continue;`
5. 编程题：写一个程序，先问用户一个数字，输入 `235` 就输出暗号，输入其它数字就照常把它打印出来。
6. 编程题：给第 11 章的"机房考勤登记"补一个隐藏命令，并在交付说明里写一句给使用者看的提示。

**测验参考答案**

| 题号 | 1 | 2 | 3 | 4 |
|------|---|---|---|---|
| 答案 | 错 | 错 | C | C |

第 1 题：`rcl(235)` 只输出一句话，不会结束程序，结束程序要用空参数的 `rcl()`。第 2 题：`rcl();` 会立刻结束程序，后面的语句不会执行。第 3 题：只有 `rcl("JF")` 是认得的字符串暗号；`rcl()` 输出的是 `方程235永远爱rcl！`，`rcl(1)` 和 `rcl("hello")` 什么也不做。第 4 题：`return` 只结束当前函数，`break` 和 `continue` 只影响循环，能让程序从任何位置整体结束的只有 `rcl()`。
