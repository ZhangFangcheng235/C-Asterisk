# 小学版教程 · C* 语言（0.5.0）

> C* 读作 **C Asterisk**。程序文件的后缀是 `.cask`。
> 这本教程写给第一次学编程的同学：会打字、会数数就够了，不需要任何基础。
> 一共 18 课，每课都有能直接按 F5 跑起来的小例子。
>
> **0.5.0 新增**：第 17 课「把东西存进文件」、第 18 课「给窗口穿上彩衣」。
> 想查细节，翻 `docs\CStar手册.md`；想练更难的题，接着看《C* 初中版教程》。

## 开始之前：先认识两个程序

安装好 C* 以后，`bin` 文件夹里有两个程序：

1. `bin\caskide.exe` —— **C* Studio**，写程序用的编辑器，界面是中文的。
2. `bin\caskc.exe` —— 编译器，把 `.cask` 文件翻译成能运行的 `.exe`。平时不用管它，你在 Studio 里按 F5，它会自动帮你叫这个程序。

双击 `bin\caskide.exe` 打开 C* Studio，会用到这里：

| 在哪儿 | 干什么 |
|--------|--------|
| 工具栏「新建 / 打开 / 保存」 | 管文件。`Ctrl+N` 新建，`Ctrl+S` 保存 |
| 工具栏「▶ 运行」「■ 停止」 | `F5` 运行，`Esc` 停下来 |
| 中间大片地方 | 写代码的位置，左边灰色的数字是行号 |
| 下面的「输出」面板 | 程序说的话、问你的事，都在这里 |
| 下面的「问题」面板 | 哪里写错了，一条条列在这儿；点一下，光标就跳过去 |
| 工具栏「代码 / 积木」 | 同一个程序的两种看法，随时切换 |
| 工具栏「格式化」 | 自动把缩进排整齐 |
| `F1` | 帮助（快捷键小抄） |
| 最下面的状态栏 | 文件名、编码、第几行第几列，还有四个计数：严重、语法、拼写、提示 |

四个计数是什么意思，见文末的「附录：常见错误」。

写好的文件要用 `.cask` 结尾，比如 `你好.cask`。

## 第 1 课　让电脑说第一句话

**这一课学什么**：把第一个程序敲进去，按 F5，看到电脑说话。

打开 C* Studio，按 `Ctrl+N` 新建一个文件，把下面这几行**一个字母一个字母**打进去：

```cask
function main() {
    print "你好，我是电脑！";
}
```

打完后按 `F5`。下面「输出」面板里会出现：

```text
你好，我是电脑！
```

这就是你的第一个程序。

**一行一行看**：

| 你写的 | 它的意思 |
|--------|----------|
| `function main() {` | 程序的开始。`main` 的意思是"主要的"，电脑从这里开始做事。每个程序都要有它 |
| `print` | 让电脑说一句话 |
| `"你好，我是电脑！"` | 双引号里的字会原样说出来。这种带双引号的文字叫**字符串** |
| `;` | 分号，表示"这句话说完了"。每一句后面都要写 |
| `}` | 最后一行，表示程序结束 |

**想说几句就说几句**：

```cask
function main() {
    print "第一句";
    print "第二句";
    print "第三句";
}
```

`print` 说完会换行，所以三句话各占一行。

**想连着说、不换行**，把 `print` 换成 `show`：

```cask
function main() {
    show "1 加 1 等于 ";
    print 1 + 1;
}
```

输出是 `1 加 1 等于 2`：`show` 说完停在原地，接着 `print` 说完再换行。

> 小提醒：双引号和分号一个都不能少。少了双引号，电脑不知道哪段是文字；少了分号，它不知道这句话说完了。

### 动手试一试

1. 把 `"你好，我是电脑！"` 换成你自己的名字，再按一次 F5。
2. 用三行 `print` 说出你最喜欢的三样东西。
3. 用 `show` 和 `print` 拼出一行：`我的名字是______，我今年______岁。`

## 第 2 课　程序的壳、注释和缩进

**这一课学什么**：看清每个程序的"壳"，学会写注释，学会看错误在哪一行。

每个 C* 程序都长这个样子：

```text
function main() {
    // 这里写你要电脑做的事
}
```

* `function` 的意思是"函数"，也就是一段可以反复用的做法。
* `main` 是这段做法的名字。电脑只从 `main` 开始做。名字前面什么都没写，说明它做完就完了，不用给答案。
* `{` 和 `}` 是一对**大括号**，要做的事写在它们中间。有开就有合，少一个都会报错。
* `//` 后面的字是**注释**，只给人和自己看，电脑完全不理它。

带注释的完整程序：

```cask
// 这是我写的第二个程序
function main() {
    print "好记性不如烂笔头";     // 注释也可以写在句子后面
    print "注释不会影响结果";
}
```

每行前面的空格叫**缩进**。不缩进程序也能跑，但大家都缩进，这样一眼就能看出谁包在谁里面。打一下 `Tab` 缩四格；懒得管就写完按工具栏的「格式化」，它会自动排好。

**写错了怎么办**：

1. 停下打字大约半秒，编辑器就在下面「问题」面板里列出问题，出错那一行的行号会变红。
2. 按 `F5` 也会先检查一遍再运行。
3. 点「问题」面板里的某一条，光标就跳到出错的地方。

故意少写一个分号，问题面板会说：

```text
S|3|1|这里要写 ';'，它要写在 print 后面，但是碰到了 '}'
```

意思是：第 3 行第 1 列，`print` 这一句少了分号。行首的 `S` 是"语法"级别，下面附录里会讲。

### 动手试一试

1. 在程序最上面写一行注释，写上今天的日期。
2. 故意删掉一个 `;`，看看问题面板怎么说。
3. 再故意删掉一个 `}`，看看又怎么说，然后把它们都加回来。

## 第 3 课　盒子：装整数（int）

**这一课学什么**：用盒子记住一个整数，需要时拿出来用，还能把里面的数换掉。

```cask
function main() {
    int 苹果 = 3;
    print "桌上有 ", 苹果, " 个苹果";
}
```

输出：

```text
桌上有 3 个苹果
```

**一行一行看**：

* `int 苹果 = 3;` —— 准备一个装**整数**的盒子，起名叫 `苹果`，先放进去 3。`int` 是整数类型，integer 的缩写。
* 盒子名可以用中文，也可以用英文，只要中间没有空格。名字最好一眼能看出装的是什么。
* 这里的 `=` 不是"等于"，而是"把右边的东西放进左边的盒子里"。
* `print "桌上有 ", 苹果, " 个苹果";` —— 用逗号把几样东西接起来，一样一样说出去。文字要加双引号，盒子名不加引号。

**盒子里的数能换**：

```cask
function main() {
    int 糖果 = 5;
    print "原来有 ", 糖果, " 颗糖";
    糖果 = 7;
    print "现在有 ", 糖果, " 颗糖";
    糖果 = 糖果 + 1;
    print "又得到一颗，变成 ", 糖果, " 颗";
    糖果 += 10;
    print "一次得到十颗，变成 ", 糖果, " 颗";
}
```

输出：

```text
原来有 5 颗糖
现在有 7 颗糖
又得到一颗，变成 8 颗
一次得到十颗，变成 18 颗
```

* `糖果 = 糖果 + 1;` 先看盒子里现在是几，加 1，再放回去。
* `糖果 += 10;` 是 `糖果 = 糖果 + 10;` 的简写。`-=`、`*=`、`/=` 也一样。
* **忘记给初值也没关系**：`int 数量;` 这样的盒子自动就是 `0`，不会冒出一个乱七八糟的数。

### 动手试一试

2. 建一个盒子装你今年的年龄，再建一个装明年的年龄，两句话打印出来。
3. 建一个装 5 颗星的盒子，先加 3 颗，再吃掉 2 颗，每做一步都打印一次。

## 第 4 课　盒子：装文字、装一个字符、装真假

**这一课学什么**：另外三种盒子 —— 装文字的 `string`、装一个字符的 `char`、装真假的 `bool`。

```cask
function main() {
    string 名字 = "小明";
    string 问候 = "你好，" + 名字 + "！";
    print 问候;

    char 首字母 = 'X';
    print "首字母是 ", 首字母;

    bool 喜欢编程 = true;
    print "喜欢编程：", 喜欢编程;
}
```

输出：

```text
你好，小明！
首字母是 X
喜欢编程：true
```

* `string` 装一串**文字**，用双引号包起来：`"小明"`、`"你好，小明！"`。
* `+` 能把两段文字接起来：`"你好，" + 名字` 就是 `"你好，小明"`。数字也能直接接进去，比如 `"一共 " + 3 + " 个"`。
* `char` 只装**一个**字符，用单引号包起来：`'X'`、`'A'`、`'7'`。单引号里写两个字符会报错。
* `bool` 只装两个值：`true`（真）和 `false`（假）。它现在看着没用，第 5 课比大小、第 6 课做判断时就要靠它。

**名词小对照**：

| 类型 | 装什么 | 例子 |
|------|--------|------|
| `int` | 整数 | `int 年龄 = 9;` |
| `float` | 小数 | `float 身高 = 1.35;`（第 9 课细讲） |
| `string` | 一串文字 | `string 名字 = "小红";` |
| `char` | 一个字符 | `char 首字母 = 'X';` |
| `bool` | 真或假 | `bool 开心 = true;` |

**老名字的一句交代**：整数、小数、文字、字符的老名字分别是 `number`、`real`、`text`、`letter`。这些老名字照样能编译，只是编辑器会在状态栏的**提示**里建议你换新的。新写的程序一律用 `int`、`float`、`string`、`char`。

## 第 5 课　算一算，比一比

**这一课学什么**：加减乘除、取余、比大小，还有 `and`、`or`、`not`。

```cask
function main() {
    print "3 + 4 = ", 3 + 4;
    print "10 - 6 = ", 10 - 6;
    print "6 * 7 = ", 6 * 7;
    print "9 / 2 = ", 9 / 2;
    print "9 % 2 = ", 9 % 2;
}
```

输出：

```text
3 + 4 = 7
10 - 6 = 6
6 * 7 = 42
9 / 2 = 4
9 % 2 = 1
```

* `*` 是乘号，`/` 是除号。键盘上没有 `×` 和 `÷`，要用这两个符号。
* 两个**整数**相除，只留整数部分：`9 / 2` 得 `4`，不是 4.5。想要 4.5，看第 9 课的小数。
* `%` 读作"取余"，就是"除完了剩下多少"：`9 % 2` 是 `1`。判断奇偶、做游戏经常用它。
* **除以 0 会当场停下并报错**，不会给你一个奇怪的结果。这是 C* 故意设计的：宁可停下，也不要算错。

**比大小**，结果是 `bool`（真或假）：

| 写法 | 意思 |
|------|------|
| `==` | 相等。注意是**两个**等号 |
| `!=` | 不相等 |
| `<` `>` | 小于、大于 |
| `<=` `>=` | 小于等于、大于等于 |

```cask
function main() {
    print "5 比 3 大？", 5 > 3;
    print "5 等于 8？", 5 == 8;
    print "5 不等于 8？", 5 != 8;
}
```

输出：

```text
5 比 3 大？true
5 等于 8？false
5 不等于 8？true
```

**把几个判断连起来**用 `and`（都要成立）、`or`（有一个成立就行）、`not`（反过来）：

```cask
function main() {
    int 年龄 = 9;
    print "是 6 到 12 岁吗？", 年龄 >= 6 and 年龄 <= 12;
    print "是 9 岁或 10 岁吗？", 年龄 == 9 or 年龄 == 10;
    print "不是 8 岁吗？", not (年龄 == 8);
}
```

输出：

```text
是 6 到 12 岁吗？true
是 9 岁或 10 岁吗？true
不是 8 岁吗？true
```

**自己加自己**：`数++` 就是 `数 = 数 + 1` 的简写，下一课做循环时天天用。

## 第 6 课　会做选择的程序（if）

**这一课学什么**：让程序看情况做不同的事。

```cask
function main() {
    int 分数 = 85;
    if (分数 >= 90) {
        print "优秀";
    } else if (分数 >= 60) {
        print "及格";
    } else {
        print "再来一次";
    }
}
```

输出：

```text
及格
```

读法：**如果……否则如果……否则……**

1. 先看 `分数 >= 90` 是不是真的。是真的，就做第一段，后面几段全跳过。
2. 不是，再看 `分数 >= 60` 是不是真的。是真的，就做这一段。
3. 都不真，就做 `else` 后面那一段。

三件事要记住：

* `if` 后面的圆括号里要放**能判断真假的东西**：比较，或者一个 `bool` 盒子。
* 圆括号里不能只写一个数字。`if (分数)` 会报错，要写 `if (分数 != 0)`。
* 每一段都老老实实加上大括号，别省。

**里面还能再套一层**（就像套娃）：

```cask
function main() {
    bool 下雨 = true;
    bool 有伞 = true;

    if (下雨) {
        if (有伞) {
            print "带伞出门";
        } else {
            print "在家看书";
        }
    } else {
        print "出去玩";
    }
}
```

输出：

```text
带伞出门
```

2. 判断一个数是正数、负数还是零（用 `> 0`、`< 0`，剩下的是零）。
3. 用 `and` 改写这个判断：分数在 60 到 100 之间才打印"这个分数是有效的"。

## 第 7 课　一遍又一遍（while）

**这一课学什么**：让程序重复做一件事，直到条件不再成立。

```cask
function main() {
    int 数 = 1;
    while (数 <= 5) {
        print "第 ", 数, " 次说你好";
        数++;
    }
    print "说完了";
}
```

输出：

```text
第 1 次说你好
第 2 次说你好
第 3 次说你好
第 4 次说你好
第 5 次说你好
说完了
```

读法：只要 `数 <= 5` 是真的，就把大括号里的事做一遍，做完再回来问一次，问到不成立为止。

大括号里有两件事：

* `print` —— 真正要做的事。
* `数++;` —— 让条件慢慢变得不成立。**少了这一句，循环就永远停不下来**，程序会一直跑，只能按 `Esc` 硬停。

写循环前，按这个顺序想三件事：**起点**（数从几开始）、**条件**（做到什么时候停）、**变化**（每一轮怎么变）。

3. 倒着数：从 10 数到 1，最后打印"发射！"。

## 第 8 课　和电脑聊天（input）

**这一课学什么**：让程序问你要一个值，读进来，再用它做事。

```cask
function main() {
    show "你叫什么名字？";
    string 名字;
    input 名字;
    print "你好，", 名字, "！";

    show "你几岁了？";
    int 年龄;
    input 年龄;
    print "你今年 ", 年龄, " 岁，明年 ", 年龄 + 1, " 岁。";
}
```

**一行一行看**：

* `show "你叫什么名字？";` —— 先问一句。用 `show` 是因为它**不换行**，你打的字就接在问号后面，看起来自然。
* `string 名字;` —— 先准备一个盒子接答案。
* `input 名字;` —— 读你打的那一行，放进盒子里。注意 `input` 后面**只写盒子名**，不写括号，也不加引号。
* `input` 一次读一整行，你打完按回车它才往下走。

数字盒子读数字，文字盒子读一整行（中间可以有空格）。数字打错了（比如打了汉字），它会说 `请输入一个整数:` 请你重打一行，不会一下子就乱掉。

**猜数字小游戏**（把前面几课都用上）：

```cask
// 电脑想一个 1 到 100 的数，你来猜
function main() {
    int 秘密 = now() % 100 + 1;
    int 猜 = 0;
    int 次数 = 0;

    print "我想了一个 1 到 100 的数，猜猜看！";
    while (猜 != 秘密) {
        show "请输入你猜的数：";
        input 猜;
        次数++;
        if (猜 < 秘密) { print "小了"; }
        else if (猜 > 秘密) { print "大了"; }
    }
    print "猜对了！你一共猜了 ", 次数, " 次。";
}
```

* `now()` 给出当前时间（一串很大的秒数），`% 100` 取它的后两位，再加 1，就得到 1 到 100 之间的一个数。
* `while (猜 != 秘密)`：只要还没猜对，就一直问。
* 第 13 课有一个更省事的写法 `RANDBETWEEN(1, 100)`。

## 第 9 课　小数（float）

**这一课学什么**：用 `float` 装小数，让除法得到小数，学会四舍五入。

```cask
function main() {
    float 身高 = 1.35;
    print "我的身高 ", 身高, " 米";

    print "9 / 2 = ", 9 / 2;
    print "9.0 / 2 = ", 9.0 / 2;

    int 总分 = 253;
    float 平均 = 总分 / 4.0;
    print "平均分 ", 平均;
    print "保留一位小数 ", ROUND(平均, 1);
    print "整数部分 ", INT(平均);
}
```

输出：

```text
我的身高 1.35 米
9 / 2 = 4
9.0 / 2 = 4.5
平均分 63.25
保留一位小数 63.3
整数部分 63
```

* `float` 装**小数**：`3.5`、`1.35`、`0.1`。带小数点的数字就是小数。
* 两个整数相除，结果还是整数（`9 / 2` 是 `4`）。**只要有一个是小数**，结果就是小数（`9.0 / 2` 是 `4.5`）。
* 小数的盒子和整数的盒子不能混着用。`int 平均 = 253 / 4.0;` 会报 `不能把 float 放进 int`，把 `int` 改成 `float` 就好。
* `ROUND(小数, 位数)` 是四舍五入：`ROUND(平均, 1)` 保留一位小数。
* `INT(小数)` 是去掉小数部分（向下取整）：`INT(63.25)` 得 `63`。

## 第 10 课　数着次数做（for）

**这一课学什么**：用 `for` 把"从几开始、做到几、每次加几"写在一行里。

```cask
function main() {
    for (int i = 1; i <= 5; i++) {
        print "第 ", i, " 次";
    }
}
```

输出：

```text
第 1 次
第 2 次
第 3 次
第 4 次
第 5 次
```

`for` 的圆括号里分三段，用两个分号隔开：

| 段 | 什么时候做 | 写什么 |
|----|-----------|--------|
| 第一段 | 开始前做一次 | `int i = 1`，准备一个计数器 |
| 第二段 | 每一轮开始前检查 | `i <= 5`，还要继续吗 |
| 第三段 | 每一轮结束后做 | `i++`，计数器加 1 |

`i` 是大家习惯给计数器起的名字。它和 `while` 做的是同一件事，只是写在一起更清楚。

**想提前停 / 想跳过一轮**：

```cask
function main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 4) { continue; }      // 第 4 轮什么都不做，直接下一轮
        if (i == 8) { break; }         // 到 8 就整圈结束
        print i;
    }
}
```

输出：

```text
1
2
3
5
6
7
```

**`for` 里还能套 `for`**，九九乘法表就是这样：

```cask
function main() {
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            show j, "x", i, "=", i * j, "  ";
        }
        print "";
    }
}
```

`show` 不换行，所以一行里能连出好几道题；一层循环做完，用 `print "";` 换一行（`""` 是两个引号挨在一起，里面什么都没有）。

## 第 11 课　一排格子（数组）

**这一课学什么**：把很多个同类的值装进一排格子，再用循环一个个访问。

```cask
function main() {
    int 成绩[5] = {88, 95, 72, 66, 100};
    string 同学[3] = {"小明", "小红", "小刚"};

    print "第一个同学 ", 同学[0], "，分数 ", 成绩[0];
    print "最后一个同学 ", 同学[2], "，分数 ", 成绩[4];
}
```

输出：

```text
第一个同学 小明，分数 88
最后一个同学 小刚，分数 100
```

* `int 成绩[5]` 是说"给我 5 个装整数的格子，排成一排"。
* `= {88, 95, 72, 66, 100}` 是开始的时候按顺序把 5 个数放进去。
* 用的时候写 `成绩[0]`：**方括号里的号码从 0 开始数**。5 个格子的号码是 `0 1 2 3 4`。
* 号码超出范围（比如写 `成绩[5]`）程序会马上停下，告诉你是哪一行，不会乱读别人的数据。

**用循环看一遍**，这是数组最常用的写法：

```cask
function main() {
    int 成绩[5] = {88, 95, 72, 66, 100};
    int 总分 = 0;
    for (int i = 0; i < 5; i++) {
        总分 += 成绩[i];
    }
    print "总分 ", 总分;
    print "平均 ", 总分 / 5.0;
}
```

输出：

```text
总分 421
平均 84.2
```

`i` 从 0 数到 4，正好和格子号码对上。注意条件是 `i < 5`，不能写 `i <= 5`：那样最后一轮会去读不存在的 `成绩[5]`，程序会报错。

## 第 12 课　自己造工具（函数）

**这一课学什么**：把一段常用的事包成一个函数，起个名字，以后叫名字就行。

```cask
// 只管做事、不给答案的函数
function 打招呼(string 谁) {
    print "你好，", 谁, "！";
}

// 要给答案的函数：答案的类型写在名字前面
int 求和(int a, int b) {
    return a + b;
}

function main() {
    打招呼("小明");
    打招呼("小红");
    print "3 + 4 = ", 求和(3, 4);
}
```

输出：

```text
你好，小明！
你好，小红！
3 + 4 = 7
```

* `function 打招呼(string 谁) { ... }` —— 名字是 `打招呼`，括号里的 `谁` 是要告诉它的东西，叫**参数**。名字前面写 `function`，表示这个函数只管做事，不给答案。
* `int 求和(int a, int b) { ... }` —— 名字前面写了答案的类型 `int`，里面用 `return` 把答案交出来。`return` 一执行，函数立刻结束，后面的句子不再运行。
* 不给答案的函数也可以写 `none 打招呼(string 谁) { ... }`，和 `function` 开头一样。
* 两个函数都写在 `main` 的**外面**，在 `main` 里像用积木一样用它。

**带判断的函数**：

```cask
string 等级(int 分) {
    if (分 >= 90) { return "优秀"; }
    if (分 >= 60) { return "及格"; }
    return "再来一次";
}

function main() {
    print "85 分：", 等级(85);
    print "100 分：", 等级(100);
    print "30 分：", 等级(30);
}
```

输出：

```text
85 分：及格
100 分：优秀
30 分：再来一次
```

参数是**复印**过去的：函数拿到的是参数的一份拷贝，在函数里怎么改，外面那个盒子都不会变。

## 第 13 课　会用表格公式就会写（大写函数）

**这一课学什么**：C* 里有一整套和 Excel 同名同义的内建函数，名字都大写。表格里的公式，几乎可以直接搬进程序。

```cask
function main() {
    int 分数 = 75;
    print "75 分算及格吗？", IF(分数 >= 60, "及格", "不及格");
    print "97 是奇数吗？", MOD(97, 2) == 1;
    print "-9 的绝对值 ", ABS(-9);
    print "3.14159 保留两位 ", ROUND(3.14159, 2);
    print "2 的 10 次方 ", POWER(2, 10);
    print "9 的平方根 ", SQRT(9);
    print "圆周率约 ", ROUND(PI(), 2);

    int 成绩[5] = {88, 95, 72, 66, 100};
    print "总分 ", SUM(成绩);
    print "平均 ", AVERAGE(成绩);
    print "最高 ", MAX(成绩), "，最低 ", MIN(成绩);
    print "一共 ", COUNT(成绩), " 个人";

    print "hello 的长度 ", LEN("hello");
    print "前两个字母 ", LEFT("hello", 2);
    print "后两个字母 ", RIGHT("hello", 2);
    print "第 2 个起取 3 个 ", MID("hello", 2, 3);
    print "变大写 ", UPPER("hi"), "，变小写 ", LOWER("HI");
    print "去掉两头空格 [", TRIM("  hi  "), "]";
    print "拼起来 ", CONCAT("a", 1, true);
    print "abc 的第 2 个字符 ", at("abc", 1);
    print "在 hello 里找 ll ", FIND("hello", "ll");
    print "把 a 换成 1 ", SUBSTITUTE("banana", "a", "1");
    print "重复 3 次 ", REPT("哈", 3);
    print "码 65 的字符 ", CHAR(65), "，a 的码 ", CODE("a");
}
```

运行结果：

```text

97 是奇数吗？true
-9 的绝对值 9
3.14159 保留两位 3.14
2 的 10 次方 1024
9 的平方根 3
圆周率约 3.14
总分 421
平均 84.2
最高 100，最低 66
一共 5 个人
hello 的长度 5
前两个字母 he
后两个字母 lo
第 2 个起取 3 个 ell
变大写 HI，变小写 hi
去掉两头空格 [hi]
拼起来 a1true
abc 的第 2 个字符 b

把 a 换成 1 b1n1n1
```

| 想干什么 | 函数 |
|----------|------|
| 二选一 | `IF(条件, 真值, 假值)` |
| 数学 | `ABS` `SIGN` `MOD` `ROUND` `INT` `SQRT` `POWER` `PI()` |
| 三角和取整 | `SIN` `COS` `TAN` `FLOOR` `CEILING` `TRUNC` |
| 一排数汇总 | `SUM(数组)` `AVERAGE(数组)` `MAX(数组)` `MIN(数组)` `COUNT(数组)` |
| 文字 | `LEN` `LEFT` `RIGHT` `MID` `UPPER` `LOWER` `TRIM` `CONCAT` `at` |
| 文字查找替换 | `FIND(文字, 要找的)` `SUBSTITUTE(文字, 旧, 新)` `REPT(文字, 次数)` `EXACT(甲, 乙)` |
| 字符和码 | `CHAR(码)` `CODE(文字)` |
| 随机和时间 | `RAND()` `RANDBETWEEN(a, b)` `now()` |

三条容易踩的坑：

* 传数组时**只写数组名字**，不写方括号：`SUM(成绩)`，不是 `SUM(成绩[])`。
* `LEFT`、`RIGHT`、`MID` 的位置**从 1 开始数**（和 Excel 一样）；`at` 是从 0 开始数的（和数组一样）。两个不一样，用的时候看清楚。
* `LEN` 数的是字节：一个英文字母算 1，一个汉字算 3。所以数"有几个字"的时候别拿它去数汉字。

**老的小写写法**（`abs`、`sin`、`floor`、`ceil` 等）还能用，但 0.4.2 起编译器会给你一条蓝色"提示"，建议改写成上面的大写名字。新写的程序一律用大写。

## 第 14 课　第一个窗口程序

**这一课学什么**：写一个真正的小窗口，上面有文字和一个按钮，点了有反应。

```cask
use "C_OPED.cash";                 // 文件最前面一行：打开 C / C++ / Win32 世界

int 次数标签;
int 点击次数 = 0;

function on_click(int 控件) {      // 按钮被点击时，C* 自动叫这个函数
    点击次数 = 点击次数 + 1;
    settext(次数标签, "你点了 " + 点击次数 + " 次");
}

function main() {
    int 窗口 = window("我的第一个窗口", 460, 260);       // 标题, 宽, 高
    label("你好，点一下按钮看看：", 24, 24, 400, 24);     // 文字, x, y, 宽, 高
    次数标签 = label("你点了 0 次", 24, 56, 400, 24);
    button("点我", 24, 104, 140, 34);
    run();                                              // 显示窗口，等到窗口关了才结束
}
```

**一段一段看**：

* `use "C_OPED.cash";` —— 第一行，把窗口这套工具请进来。写了它，C、C++ 和 Win32 的函数也能直接叫，不用再写 `include`。
* `int 次数标签;` 和 `int 点击次数 = 0;` 写在所有函数**外面**，每个函数都能看到。要记住"哪个是标签、点了多少次"，就得这么写。
* `function on_click(int 控件) { ... }` —— 这是**事件函数**：有控件被点了，C* 就来叫它，参数 `控件` 是被点的那个控件的编号。你写了它才会被叫；不写也行，只是按钮点了没反应。
* `window("标题", 宽, 高)` 开一个窗口，返回一个**编号**，存进 `窗口` 里。
* `label(文字, x, y, 宽, 高)` 放一段文字。`x, y` 是它左上角离窗口左上角多远（单位是像素），后两个数是它占多大地方。
* `button(文字, x, y, 宽, 高)` 放一个按钮。按钮和标签的用法一模一样，只是多了能点的功能。
* `run();` 让窗口显示出来，在这里等你点，直到你关掉窗口才往下走。**不写 `run()`，窗口一闪就没了。**
* `settext(控件, "文字")` 把某个控件上的文字换掉。

**运行**：还是按 `F5`。窗口程序默认**没有黑色控制台**。调试的时候想在黑色窗口里看到 `print` 的结果，用命令行这样跑：

```bat
bin\caskc.exe 程序.cask --run --console
```

## 第 15 课　窗口里能写、能勾、能弹框

**这一课学什么**：输入框、勾选框、进度条，还有弹出来的对话框。

```cask
use "C_OPED.cash";

int 名字框;
int 结果标签;
int 按钮;

function on_click(int 控件) {
    if (控件 != 按钮) return;                    // 只理按钮，别的控件不管
    string 名字 = readtext(名字框);               // 把输入框里的字读出来
    if (名字 == "") {
        settext(结果标签, "先在框里写上名字");
        return;
    }
    settext(结果标签, 名字 + "，你好！");

function main() {
    int 窗口 = window("打招呼", 460, 260);

```

**新东西**：

* `textbox("初值", x, y, 宽, 高)` 是单行输入框，`readtext(控件)` 把里面的字读出来。
* `if (控件 != 按钮) return;` 是"守门员"：窗口里控件多了以后，用它保证只有按钮做正事。

* `alert("内容")` 弹一个小对话框，点确定就关掉。

**再来一个：勾选框和进度条。**

```cask
use "C_OPED.cash";

int 勾选框;
int 进度条;
int 进度标签;
int 按钮;

function on_click(int 控件) {
    if (控件 != 按钮) return;
    if (checked(勾选框) == 1) {
        setvalue(进度条, 100);
        settext(进度标签, "全部做完啦");
        msgbox("真棒", "表扬");

        setvalue(进度条, 50);
        settext(进度标签, "先勾上「我把作业做完了」");

function main() {

    按钮 = button("看看进度", 24, 136, 120, 32);
    run();
}
```

| 想干什么 | 怎么写 |
|----------|--------|
| 弹出消息（带标题） | `msgbox("内容", "标题");` |
| 问"是 / 否" | `if (ask("要做吗？", "问一句") == 1) { ... }`，1 是"是"，0 是"否" |
| 勾选框 | `int 勾 = checkbox("文字", x, y, 宽, 高);` |

| 进度条 | `int 条 = progress(x, y, 宽, 高);` |
| 设置进度 | `setvalue(条, 60);`，读进度用 `getvalue(条)` |
| 多行输入框 | `memo("文字", x, y, 宽, 高)` |
| 等一会儿 | `sleep(1000);`（1000 毫秒 = 1 秒） |

## 第 16 课　做一个小作品：待办清单

**这一课学什么**：把前面学的控件凑成一个真能用的小程序。

```cask
use "C_OPED.cash";

int 输入框;
int 列表;
int 提示标签;

function on_click(int 控件) {
    string 一件事 = readtext(输入框);
    if (一件事 == "") {
        settext(提示标签, "先写一件事，再点添加");
        return;
    }
    additem(列表, 一件事);            // 往列表里加一行
    settext(输入框, "");             // 清空输入框，好写下一件
    settext(提示标签, "已加入：" + 一件事);
}

function main() {
    int 窗口 = window("我的待办清单", 480, 340);
    label("要做的事：", 20, 20, 90, 24);
    输入框 = textbox("", 110, 20, 240, 24);

    提示标签 = label("写下第一件事吧", 20, 56, 440, 24);
    列表 = listbox(20, 92, 440, 220);
    run();
}
```

**新东西**：

* `listbox(x, y, 宽, 高)` 是一个列表，`additem(列表, "一项")` 往里加一行。加进去的行会自己一行行排下来。
* `on_click` 里先读出输入框的字。空的话提醒一句就 `return`——在这里 `return` 的意思是"这次点击不做了，回去等下一次"。
* `settext(输入框, "")` 把输入框清空，方便接着写下一件。

**还能做**：

| 想做什么 | 用什么 |
|----------|--------|
| 改控件的文字 | `settext(控件, "新文字")` |
| 改控件的标题 | `settitle(控件, "新标题")` |
| 输入框内容一变就有反应 | 写 `function on_change(int 控件) { ... }` |
| 窗口被关时收个尾 | 写 `function on_close() { ... }` |
| 删掉某个控件 | `destroy(控件)` |

**打开 C 的世界**：第一行写了 `use "C_OPED.cash";` 之后，C 和 C++ 的函数可以直接叫，不用再写什么 `include`。比如：

```text
int 毫秒 = GetTickCount();      // 程序启动到现在过了多少毫秒
int 数 = atoi("42");            // 把文字 "42" 变成整数 42
```

`atoi` 这种 C 函数很有用：输入框里读出来的是文字，想拿它算数，就请 `atoi` 帮忙变成整数。

**C# 不行**：C# 没有 C 头文件，所以窗口程序只能请 C、C++ 和 Win32 帮忙，用不了 C#。

**调试**：窗口程序默认没有黑色控制台。想在控制台里看 `print`，用 `bin\caskc.exe 程序.cask --run --console`。

## 第 17 课　把东西存进文件

**这一课学什么**：让程序记住东西——关掉再打开，写过的内容还在。

前面程序里的变量都住在内存里，程序一关就全没了。想让"我的记录本"下次打开还在，
要把内容写进**文件**。C* 用 `use "C_IO.cash";` 打开文件工具箱：

| 写法 | 意思 |
|------|------|
| `writefile(路径, 内容)` | 把整段文字写进文件（覆盖原来的），成功返回 1 |
| `readfile(路径)` | 把整个文件读成一段文字；文件不存在时是 `""` |
| `fileexists(路径)` | 文件在不在：在是 1，不在是 0 |
| `appdir()` | 本程序（exe）所在的文件夹，用它拼路径最省事 |

```cask
use "C_OPED.cash";
use "C_IO.cash";

int 记录框;
int 状态;

function on_click(int 控件) {
    string 文件 = appdir() + "/我的记录.txt";
    if (writefile(文件, readtext(记录框)) != 0)
        settext(状态, "已经保存到：" + 文件);
    else
        settext(状态, "保存失败，看看这个文件夹能不能写");
}

function main() {
    string 文件 = appdir() + "/我的记录.txt";
    int 窗口 = window("我的记录本", 460, 330);
    label("写点想记住的事：", 20, 16, 420, 24);
    记录框 = memo("", 20, 48, 420, 190);
    状态 = label("", 20, 246, 420, 24);
    button("保存", 20, 280, 120, 34);
    if (fileexists(文件) != 0) settext(记录框, readfile(文件));
    run();
}
```

**新东西**：

* `memo` 是多行输入框，适合写一段话；`readtext(记录框)` 一次读出全部内容。
* `appdir() + "/我的记录.txt"` 把文件放在 exe 旁边，不用自己猜路径。
* 程序启动时先用 `fileexists` 问一句：有旧文件就 `readfile` 读出来，填回输入框。
* 点「保存」才写文件；不点就什么都不改，很安全。

**注意**：`readfile` 一次最多读 1MB，写日记、记名单足够用。

## 第 18 课　给窗口穿上彩衣

**这一课学什么**：用 `C_CSS.cash` 给窗口、标题、输入框和按钮换颜色、改字号。

前面做的窗口都是系统默认的灰底。C* 还有一个美化工具箱，只要在
`use "C_OPED.cash";` 后面再写一行 `use "C_CSS.cash";`：

| 写法 | 意思 |
|------|------|
| `cstext(控件, 颜色)` | 改文字颜色 |
| `csbg(控件, 颜色)` | 改背景颜色 |
| `csfont(控件, 字号, 加粗)` | 改字号（磅）和粗细；加粗写 1，不加粗写 0 |
| `csbg(窗口, 颜色)` | 改整个窗口的底色 |

颜色写 `"#RRGGBB"`（红绿蓝各两位），也可以写 `"red"`、`"gold"` 这样的颜色名。

```cask
use "C_OPED.cash";
use "C_CSS.cash";

int 名字框;
int 提示;

function on_click(int 控件) {
    settext(提示, "你好，" + readtext(名字框) + "！");
}

function main() {
    int 窗口 = window("彩色问候", 460, 280);
    int 标题 = label("你好，C* 0.5.0！", 20, 20, 420, 40);
    名字框 = textbox("小明", 20, 80, 280, 28);
    int 按钮 = button("打个招呼", 20, 130, 160, 40);
    提示 = label("在这里写名字", 20, 196, 420, 24);

    csbg(窗口, "1B2129");            // 深蓝黑窗底
    cstext(标题, "#FFD166");         // 金黄色标题
    csfont(标题, 22, 1);             // 22 磅、加粗
    csbg(名字框, "0D1117");          // 输入框深色底
    cstext(名字框, "#E6EDF3");       // 输入框浅色字
    csbg(按钮, "238636");            // 绿色按钮
    cstext(按钮, "#FFFFFF");
    csfont(按钮, 12, 1);
    cstext(提示, "#8B949E");
    run();
}
```

**新东西**：

* `csbg(窗口, ...)` 连窗口自己的底色也能换。
* 按钮的颜色在 Windows 上也真的会变——0.5.0 把按钮改成了自绘。
* `csfont` 的单位是**磅**，12 磅大约 16 像素，数字别写太大。
* 圆角 `csradius` 和投影 `csshadow` 只在 Linux 上有效，Windows 上写了也没关系，不会报错。

## 彩蛋时间：`rcl`

写到这里你可能已经会很多东西了。藏一个小秘密：C* 里有一个内置函数叫 `rcl`，它不用 `use`、不用自己写函数体，直接调用就行。

- `rcl(235);` 或者 `rcl("FC235");` —— 会打印出 `rcl 爱 方程235`，然后继续往下走。
- `rcl("rcl");` —— 打印出 `方程235，rcl永远爱你！`。
- 空着的 `rcl();` —— 打印出 `rcl永远爱方程235！`，然后**整个程序就停了**，后面的话一句也不执行。可以把它当成一个"急停"按钮。
- 别的值（比如 `rcl(1);`、`rcl("hello");`）—— 什么都不做，程序照常跑。

它认的字符串暗号（不分大小写）有：`235`、`方程235`、`FangCheng235`、`ZFC235`、`JF235`、`JF`、`FC235`、`FC`、`ZFC`、`FangCheng`。

试试看：把你的名字或班级编号藏在 `rcl` 里，写个"只有我们班才看得懂"的小程序。

## 附录：常见错误

**先认识四个计数。** 状态栏最右边有四个数字，是四类问题的条数：

| 计数 | 字母 | 颜色 | 什么意思 |
|------|------|------|----------|
| 严重 | `E` | 红 | 程序跑不起来。比如把小数塞进 `int`、名字根本没定义、`if` 里只写了一个数字 |
| 语法 | `S` | 橙 | 写法不对：少分号、括号或大括号不配对。编译器会跳过错的地方继续看，所以一次能报好几条 |
| 拼写 | `P` | 绿 | 名字打错了。像的时候后面还会附一句"是不是想写 ×××" |
| 提示 | `H` | 蓝 | 不算错，只是建议。比如你还在用老名字 `number`、`text`、`say`，它提醒你换成 `int`、`string`、`print` |

前三种会让程序跑不起来，最后一种不影响运行。问题面板里每条长这样：

```text
demo.cask:3:1: 错误: 这里要写 ';'，它要写在 print 后面，但是碰到了 '}'
```

读法是 `文件:行:列: 错误: 说明`。点一下这一条，光标就跳过去。

**初学最容易犯的八个错**：

| 你写的 | 编辑器会说什么 | 怎么改 |
|--------|----------------|--------|
| `print "你好"`（少了分号） | 语法（S）：`这里要写 ';'，它要写在 print 后面，但是碰到了 '}'` | 句尾补一个 `;` |
| `if (分数 > 60 { ... }`（圆括号没关） | 语法（S）：`这里要写 ')'，它用来关掉 if ( ... )，但是碰到了 '{'` | 在 `60` 后面补一个 `)` |
| `if (分数 = 60)`（一个等号当成比较） | 严重（E）：`条件必须是一个比较（true 或 false），不能是 int —— 例如写 'n != 0'` | 改成 `if (分数 == 60)`，比较要用两个等号 |
| 直接在外面写 `print "你好";` | 语法（S）：`顶层只允许写 'use'、'constant'、变量声明、函数和 'function main() { ... }'（这里是 'print'）` | 把句子放进 `function main() { ... }` 里面 |
| 忘了写 `function main()` | 严重（E）：`程序没有入口 —— 请加一个 'function main() { ... }' 块（或者 'start { ... }'）` | 加上 `function main() { ... }`，所有要运行的句子都放进去 |
| 少写一个 `}` | 语法（S）：`少了 '}'，也就是 'main' 的函数体` | 数一数 `{` 和 `}` 是不是一样多，多半缺在最后 |
| `print 分树;`（名字打错） | 拼写（P）：`不认识的名称 '分树'，是不是想写 '分数'？` | 改成对的盒子名 `分数` |
| `int 平均 = 253 / 4.0;`（类型对不上） | 严重（E）：`不能把 float 放进 int` | 把 `int` 改成 `float` |

还有一种错不是编译出来的，是**程序跑到一半才出错**。比如：

```text
C* 运行错误: 除以零
  位置 demo.cask:7
```

它的意思是第 7 行除数是 0。数组越界也一样，会告诉你 `数组下标越界` 和出错的行号。看到这种信息，就去看那一行的除数和方括号里的号码。C* 遇到这种错会**立刻停下**，不会接着乱算——这是好事，它帮你把问题指出来了。

**最后一种：程序跑完了，但结果不对。** 这种最难找，办法是：一次只改一样东西，中间多加几个 `print`，把盒子里的数打出来看看对不对。比如怀疑平均分算错了，就先把总分打出来，看看总分对不对。
